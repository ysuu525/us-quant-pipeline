## 1. 信号 #2 冻结定义

以下规格块与实现者共用同一份文本，**逐字冻结**：

```
intraday_t  = |DlyClose_t| / |DlyOpen_t| − 1         （两者 > 0 且有限，否则 NaN）
overnight_t = (1 + DlyRet_t) / (1 + intraday_t) − 1
score(t)    = Σ_{s = t−20 .. t} intraday_s             （21 个交易日含 t；有效值 < 15 或跨度 > 31 → NaN）
score_overnight(t) 同法，只作诊断
LOOKBACK=21, MIN_VALID=15, MAX_SPAN_DAYS=31：文献/日历先验，不可调
截面不 winsorize、不 z-score；评估用 Spearman 秩
出处：Lou-Polk-Skouras 2019 JFE；Barardehi-Bogousslavsky-Muravyev 2026 RFS
实现：src/signals/overnight_intraday.py；spec_hash 待实现完成后回填
```

### 1.1 归类的诚实标注（不改规格，只标口径）

按 `docs/调研_合成与验证设计_2026-09-03.md` §四隐性污染渠道 ④（「零自由参数通常是假的」），
把上面三个常数逐条归类：

| 常数 | 归类 | 说明 |
|---|---|---|
| `LOOKBACK=21` | **文献先验** | LPS 2019 的「过去 1 个月日内累计收益」，21 交易日 ≈ 1 日历月 |
| `MIN_VALID=15` | **本项目设定的缺失处理常数**，冻结不可调 | 文献未规定；写死是为了不可调，不是因为有文献支持 |
| `MAX_SPAN_DAYS=31` | **本项目设定的陈旧处理常数**（日历先验），冻结不可调 | 同上 |

另有三处**已知的口径迁移**，属披露不属缺陷：

1. LPS 2019 是**月频调仓、十分位**读数；本项目在 **6 日 execution-return 标签**上按**逐日**读 RankIC。
   两者不是同一个量，文献量级不能直接搬（这正是 §3 要做折算的原因）。
2. `score(t)` 是日内收益的**算术和**，不是几何累积。差异在 21 日、日内收益量级下为二阶小量，
   但**它是一个实现选择**，冻结在此。
3. 复权口径：`DlyRet` 已含分红与拆分，`DlyOpen`/`DlyClose` 为原始价。
   `intraday_t` 只用同日 open/close 之比，**除权日内部无跨日因子**，故不需要 `DlyFacPrc`；
   `overnight_t` 由 `DlyRet` 反解得到，除权效应自动落在隔夜段——这与 LPS 的处理一致，**记录在案**。

### 1.2 工程约束（`CLAUDE.md` §七）

  + 日期下推过滤 + 分块（K15 用的 2 年一块是已验证的范式）。

## 3. 功效声明（诚实）

按 `CLAUDE.md` §二强制要求，三样一起写下。

### 3.1 SESOI

**SESOI = IC₂ ≥ 0.0085**（6 日标签、top500 口径）。

来源不是主观：它是**稀释门槛**——等权秩相加要不损害信号#1，
需 `IC₂ > IC₁ × (√(2(1+ρ₁₂)) − 1)`（调研 B 式(2)），
代入 `IC₁ = 0.0155`（0.0207 打 25% 赢家诅咒折价）、`ρ₁₂ = 0.2` 得 **0.008513**。
低于它，加信号#2 在等权规则下是负增益，**不值得据以决策**——这正是 SESOI 的定义。

### 3.2 预期效应

调研 A 推断隔夜/日内分解的**月频 IC 约 0.02–0.03**（该推断本身标注为「大盘股子样本量级未核到」）。
按 `IC_h ∝ √h` 换到 6 日标签：`√(6/21) = 0.5345`

```
0.020 × 0.5345 = 0.0107
0.030 × 0.5345 = 0.0160
```

**预期 IC₂（6 日标签）= 0.010–0.016。**

### 3.3 SE 与 MDE

Kronos 在同一 832 天上的 NW 标准误：`SE₁ = 0.0207 / 3.63 = 0.0057`（`HANDOFF.md` §2）。
信号#2 是慢信号，`score(t)` 的 21 日重叠窗使逐日 IC 的自相关**高于** Kronos，
NW 长期方差随之抬高。取 **1.0–1.5×**：

```
SE₂ ∈ [0.0057, 0.0086]
MDE80 = 2.8016 × SE₂ ∈ [0.016, 0.024]        （双侧 α=0.05，功效 80%，Z = 1.96 + 0.8416）
```

**目标功效：80%。**

### 3.4 判定：不是确认性检验

```
MDE80 / SESOI = 0.016/0.0085 … 0.024/0.0085 = 1.9 … 2.8   → 全部 > 1
MDE80 的下界 0.016 = 预期效应的上界 0.016                  → 最乐观处也只有 80%，一般情形远低
```

在预期效应处的实际功效（由 §3.2、§3.3 的数直接算出，非新假设）：

| 效应 | SE=0.0057 | SE=0.0086 |
|---|---|---|
| 0.010 | 41% | 20% |
| 0.013 | 63% | 33% |
| 0.016 | 80% | 48% |

**结论（措辞按 `CLAUDE.md` §二强制格式）**：

> **「信号#2 vs 零」在开发折 36–42 上不构成确认性检验。在本样本量下该问题不可回答。**
> 本预注册 §4 的处置规则以点估计门控，属 **B 层「按先验规则决定」**，
> 是**资源分配规则**，不是统计推断。

由此推出两条强制措辞，任何后续引用必须照写：

- C 档触发时**不得**写成「信号#2 无效 / 被否定 / 检验未通过」。
  正确写法：**「在本样本量下该问题不可回答，按预先规则不为信号#2 分配确认集资源。」**
  （`CLAUDE.md` §二：MDE > SESOI 时不得据其未过门槛得出否定结论。）
- A/B 档触发时**不得**写成「信号#2 被证实有效」。
  正确写法：**「按预先规则取合成规则 X」**，读数标为方向性证据、非无偏估计
  （折 36–42 已消耗，`CLAUDE.md` §四）。

## 4. 三分处置（看数据前写死）

### 4.1 三个量的定义

```
IC₂ = top500 逐日 RankIC 均值（折 36–42 拼接为一条逐日序列后取均值）
ρ   = 与 Kronos FT 的逐日截面 Spearman 秩相关的跨日均值（= ρ₁₂）
k⁺  = 折 36–42 中「折内 top500 逐日 RankIC 均值 > 0」的折数
```

### 4.2 处置

| 档 | 条件 | 处置 |
|---|---|---|
| **A** | `IC₂ ≥ 0.0085` **且** `ρ < 0.30` **且** `k⁺ ≥ 4/7` | 合成规则取**等权秩相加**：`src/portfolio/combine.rank_sum_equal_weight` |
| **B** | `0.005 ≤ IC₂ < 0.0085` **且** `ρ < 0.30` **且** `k⁺ ≥ 4/7` | 合成规则取**慢信号筛子**：`src/portfolio/combine.slow_filter`，`keep_frac=0.50`，持仓按名次固定 **50 只** |
| **C** | 其它（含 `IC₂ < 0.005`、或 `ρ ≥ 0.30`、或 `k⁺ ≤ 3`） | 信号#2 **终止**：不进入任何合成，不进入折 05–35 |

### 4.3 阈值来源

| 阈值 | 来源 | 归类 |
|---|---|---|
| `0.0085` | 稀释门槛 `IC₁ × (√(2×1.2) − 1)`，`IC₁ = 0.0207 × (1−0.25) = 0.0155`，调研 B 式(2) | 派生自文献+本项目实测 |
| `0.005` | 0.0085 的一半，作 B 档下限 | **设计常数（我方设定）** |
| `ρ < 0.30` | 调研 A 合格标准 (a)「低相关」，其数值化见调研 A §三执行建议「ρ<0.3」 | 文献推断 |
| `k⁺ ≥ 4/7` | `CLAUDE.md` §一.3 要求判据必须含一致性门槛；**该条只要求门槛存在，未给具体数**。4/7 是本项目历史用法（`HANDOFF.md` §2「4/7 折」）在开发折上的沿用 | **设计常数（我方设定）** |

**核对（不改判据，只披露门槛对参数的敏感性）**：稀释门槛 `IC₁ × (√(2(1+ρ)) − 1)` 随 ρ 与 IC₁ 变化——

| IC₁ 取法 | ρ=0.2 | ρ=0.3 |
|---|---|---|
| 0.0155（全池 × 0.75 折价，调研 B 所用） | **0.00851** | 0.00949 |
| 0.0207（全池开发折实测，未折价） | 0.01137 | 0.01268 |
| 0.0258（top500 开发折实测，未折价） | 0.01417 | 0.01580 |

即：A 档用的 0.0085 是上表**最宽松的一格**；若 ρ 实测落在 0.2–0.3 之间、或认为
「与 IC₂ 同口径的 IC₁ 应取未折价值」，门槛都应更高。
**这个不一致来自上游文档（见附录 A 第 3 条），本预注册按任务口径字面执行 0.0085，
并在此显式披露。**

### 4.4 明文条款

1. **三档处置不比较任何合成规则的收益或 IC。** 处置只是「按先验规则取 X」，
   `CLAUDE.md` §二 B 层措辞适用。
2. **处置后不得回头改阈值。** 若需修订，必须显式记录「修订发生在看到结果之后」并说明
   修订理由是先验方法学问题（`CLAUDE.md` §二）。
3. **若结果落在边界附近**（例如 `IC₂ = 0.0084` 或 `ρ = 0.299`），**按字面执行并披露**。
   不设「接近即视为通过」的模糊地带。
4. **不复算、不重跑挑好的那次。** 计算是确定性的：seed、快照 ID、`spec_hash` 全部登记。
5. 若 `ρ` 对 FT 与 ZS 给出跨档的不同答案（一个 <0.30 一个 ≥0.30），**按 FT 的值字面执行**，
   同时把 ZS 的值原样披露（见附录 A 第 6 条）。

## 6. 对确认协议 v4 的追加条款（待并入，本文件不使 v4 生效）

### 6.1 固定序贯检验

```
H1: Kronos 单臂 vs 零        —— 现有 E / S 终点，α = 0.05
H2: 合成      vs 零          —— 同一 E / S 口径，α = 0.05
顺序事先写死；H1 不拒绝则 H2 不读。不拆 α（fixed-sequence 强控 FWER）。
```

依据：调研 B §一②与 §四预注册第 3 条（FDA 2022 多终点指南的 fixed-sequence 做法）。
顺序不可颠倒：单臂功效更高，应当放在门控第一位。

### 6.2 ΔIC 的地位

`ΔIC = IC(合成) − IC(单臂)` 在 31 折上 **MDE80 = 0.0050–0.0079，SESOI = 0.002–0.0031
→ MDE/SESOI = 1.6–4.0 → B 层**（调研 B §二(6)(7)）。

**只报点估计与 95% CI，不做任何淘汰、不做任何推翻。** 措辞强制：

> **在本样本量下该问题不可回答。**

**不得**写成「合成与单臂不可分」或「两者相等」（`CLAUDE.md` §二措辞强制）。

### 6.3 部署规则（是规则，不是检验）

```
部署合成  ⟺  H1 拒绝  ∧  H2 拒绝  ∧  折 05–35 上 ΔIC ≥ 0
```

三个条件全部预先写死。`ΔIC ≥ 0` 是一个**符号门**，不附带显著性要求——
正因为它不可能显著，才必须写成规则而非检验（调研 B §四预注册第 4 条）。

### 6.4 信号#2 在折 05–35 上的计算方式

**按 §1 冻结规格滚动计算，无训练、无拟合、无任何在确认折上估计的参数。**
计算与 Kronos 的封存打分同样受 `src/crsp_pipeline/sealed.py` 的哨兵与 `assert_readable` 守卫约束；

## 附录 A：撰写中发现的上游文档矛盾（披露，**不裁定**）

以下六条是本文件在整合各上游文档时发现的**互相冲突之处**。
它们**不改变** §4 判据的字面执行，需要用户裁定的部分已标出。

**1. 合成规则的推荐，三份文档给出三种排序。**
- `docs/调研_合成与验证设计_2026-09-03.md` §三第2条推荐顺序为 **(c) meta-labeling > (b) 筛子**，
  §四正式推荐 **(b) 筛子**，并明文写「**逐日秩相加（方案 a）被排除**」。
- `docs/思路整理_2026-09-03.md` §6.1 把 **(a) 等权秩相加**作为 A 档（IC₂ ≥ 0.0085）的处置，
  理由是「上游默认 1/N」。
- 本预注册 §4 按后者执行。
→ **即：调研 B 明确排除的方案，被思路整理设为最优档的处置。** 需用户裁定。

**2. 预期 IC₂ 的两个先验相差一倍，且落在处置阈值的两侧。**
- 调研 A 推断月频 IC **0.02–0.03** → 6 日标签 **0.0107–0.0160** → 可能落 A 档。
- 调研 B §二(10) 的算例假设 IC₂(21 日) = **0.010–0.015** → 6 日标签 **0.0053–0.0080**
  → **全部低于 0.0085**，调研 B 据此写「此时逐日秩相加**确定是负增益**」。
→ 同一个量的两份先验差约 2×，且分别落在 A 档与 B/C 档。本预注册按调研 A 的口径写 §3.2，
  但**该分歧未解决**。

**3. 稀释门槛 0.0085 的 IC₁ 基准与 IC₂ 的读数口径不对称。**
- 0.0085 由 `IC₁ = 0.0155`（= 全池 0.0207 × 0.75 赢家诅咒折价，即**确认折的预期值**）导出；
- 但 IC₂ 将在**开发折 36–42、top500 池**上读，该口径下 Kronos 实测是 **0.0258**（未折价）。
- 调研 B §二(4) 自己也提出「信号#2 的超参也在折 36–42 选，凭什么不折？」并给出折价后的 IC₂。
→ 用「折价后的 IC₁」配「未折价的 IC₂」、用「全池 IC₁」配「top500 IC₂」，是两层口径不对称，
  方向都使 A 档更容易触发。§4.3 的敏感性表给出了另外四格。**需用户裁定用哪一格。**

**4. `ρ` 在 0.2–0.3 之间时，A 档阈值不足以保证不稀释。**
处置允许 `ρ < 0.30`，但 0.0085 是在 `ρ = 0.2` 处算的；`ρ = 0.3` 时同一公式给 **0.00949**。
→ 若实测 `ρ ∈ [0.2, 0.3)` 且 `IC₂ ∈ [0.0085, 0.0095)`，字面执行会取等权秩相加，
  而该参数组合下等权秩相加按调研 B 自己的公式**是稀释的**。

**5. 以 IC 门控合成规则，与 `CLAUDE.md` §五自身的降级令相抵。**
- `CLAUDE.md` §五：「RankIC 已降级为诊断」「不作决策依据」，主指标是净夏普；
  机制是「收益 ≈ IC × 截面离散度」，且 IC 看全截面、组合只吃两端。
- 调研 B §三第2条同向：「**IC 口径系统性低估慢信号**，用 IC 选合成方式会系统性选错」。
- 项目内唯一一次等权秩相加实测（K8，ZS+FT）恰恰是 **IC +28% 而 top-decile 价差 −16%**
  （`HANDOFF.md` §10.4），即 IC 与钱反号。
→ 本预注册的三分处置**完全以 IC₂ 门控**。这是一个**已知的、被两份文档同时警告过的**方法学风险，
  但用 IC 之外的量门控又会要求在 36–42 上比较合成规则的钱——那是被 §5 明文禁止的。
  **两难，需用户裁定。** 本文件按任务口径执行 IC 门控并在此披露。

**6. 「Kronos 单臂」在双臂裁定下指代不明。**
