## 0. 定位：探索性诊断，不是确认性检验

- 用户裁定（09-05）：「不测就不上；文献搜不到不等于不测」。本探针把 ICT/SMC 里能在
  **日频 K 线**上机械化的概念写成**零调参规则**，在**已消耗折**上量化其信息含量。
- 按 CLAUDE.md §二「功效关」：本项目信噪比下，预期 **MDE > SESOI**（估算见 §5），
  因此本探针**只能是探索性**：通过门槛 ≠ 采纳，未通过门槛 ≠ 否定。
  唯一可能的正面产出是「值得升级为正式预注册臂候选」，之后仍须在未消耗数据上确认。
- 措辞强制（CLAUDE.md §二 B 层）：不得写「不可分」「两者相等」。未达门槛一律写
  「在本样本量下该问题不可回答」。

## 1. 问题

- **Q1 独立信息**：某个 ICT 标记在信号日 t 触发，对该股 6 日执行收益（去当日截面均值）
  有没有预期方向的偏移？
- **Q2 对 Kronos 的增量**：在 Kronos 分数秩条件下，标记有没有增量？具体两问：
  (a) Fama–MacBeth 日截面回归里标记主效应与秩×标记交互项；
  (b) 策略层直接可用的读数：Kronos **前五分位**内，看涨标记触发 vs 未触发的收益差
  （多头腿过滤价值）；**后五分位**内，看跌标记触发 vs 未触发（空头腿过滤价值）。

## 3. 标记定义（全部只用 ≤ t 日的 K 线；参数写死，不调）

固定参数：摆动回看 **L = 20** 个交易日；ATR 窗 **14**（用 t-1 及之前）；位移倍数 **k = 1.5**；
订单块回看 **5** 根；订单块 / OTE 有效期 **20** 个交易日。记 `H20 = max(High[t-20..t-1])`，
`L20 = min(Low[t-20..t-1])`，`TR_t = max(H_t−L_t, |H_t−C_{t-1}|, |L_t−C_{t-1}|)`。

| 编号 | 名称（ICT 术语） | 看涨定义（t 日触发） | 看跌定义 |
|---|---|---|---|
| P1 | 扫流动性后收回（liquidity sweep / turtle soup） | `Low_t < L20` **且** `Close_t > L20` | `High_t > H20` 且 `Close_t < H20` |
| P2 | 结构突破（break of structure, BOS） | `Close_t > H20` | `Close_t < L20` |
| P3 | 三根 K 线失衡（fair value gap, FVG）形成 | `Low_t > High_{t-2}` | `High_t < Low_{t-2}` |
| P4 | 位移 K 线（displacement） | `TR_t > k·ATR14_{t-1}` 且 `(C_t−O_t)/(H_t−L_t) ≥ 0.6` | 同左，且 `(O_t−C_t)/(H_t−L_t) ≥ 0.6` |
| P5 | 订单块回测（order block retest） | 设 t0 日 P2 看涨触发；订单块 = t0 前 5 根内**最后一根**阴线（C<O）的 [Low, High]；在 t0 < t ≤ t0+20 内，`Low_t ≤ OB_high` 且 `Close_t > OB_low` 的**首个** t 触发 | 镜像：t0 日 P2 看跌触发，订单块 = 最后一根阳线；`High_t ≥ OB_low` 且 `Close_t < OB_high` 首个 t |
| P6 | 最优入场回撤（OTE，62–79% 回撤） | 设 t0 日 P2 看涨触发，腿 = [`L20(t0)`, `High_{t0}`]，区间 = [腿低 + 0.21·腿长, 腿低 + 0.38·腿长]；在 t0 < t ≤ t0+20 内，`Low_t` 进入区间、`Close_t ≥ 区间下沿`、且期间未破腿低的**首个** t | 镜像 |

约定：
- 每个标记是布尔量；同一股同一日可多标记并存，各自独立评估。
- P5/P6 若 t0 后未满足条件，不触发；一个 t0 只允许一次触发。
- 数据不足以计算（回看不够、缺 OHLC）记为不可算，该观测从该标记的分析中剔除，并报告剔除比例。
- 定义有歧义处，执行者取**最简读法**，在报告里写明，**不得**同时跑多种读法。

## 4. 统计量

设 `y = label − 当日观测集内 label 均值`（去截面均值），另报 y 按日 1%/99% 截尾版。

- **Q1**：对每个标记 f，每日取触发股的 `y` 均值（当日触发数 < 5 则该日跳过），得日序列；
  报均值、NW(lag=6) SE、t、事件数、触发日数；按折报均值，并数「预期方向同向折数 / 有效折数」
  （有效折 = 该折事件数 ≥ 20）。看涨预期为正，看跌预期为负。
- **Q2(a)**：每日截面回归 `y = a + b1·kr + b2·f + b3·(kr−0.5)·f`，`kr` = 当日 Kronos 分数百分位秩；
  Fama–MacBeth 汇总 b2、b3 的均值与 NW(lag=6) t。
- **Q2(b)**：每日在 Kronos 前五分位内算「看涨 f 触发 − 未触发」的 y 均值差（触发数 < 5 跳过）；
  后五分位内算「看跌 f 触发 − 未触发」；日序列 → 均值、NW SE、t、同向折数。
- **Q0 描述**：各标记触发率（占股·日）、标记间重叠、每折事件数。这是理解结果的前提。

## 5. SESOI、MDE、功效（先于结果）

- **SESOI = 10 bp / 6 日持有期**（Q1 的 `y` 均值；Q2(b) 的触发−未触发差）。
  理由：本项目盈亏平衡成本约 22 bp 双边，10 bp 约为成本预算之半；再小的过滤价值不改变决策。
- **MDE = 2.80 × NW SE**（双侧 5%、功效 80%），每个标记按其实际日序列算出并报告。
- **先验估算**（写在看结果前）：假设触发率约 3–5%、日均约 15–25 个事件、个股 6 日特质波动约 6%，
  日均值 SE ≈ 1.2–1.5%，有效独立日 ≈ 1380/6 ≈ 230，NW SE ≈ 8–10 bp，**MDE ≈ 22–28 bp > SESOI**。
  故本探针**预计分辨不了 SESOI 量级的效应**，定位为探索性。若实际 MDE ≤ SESOI，
  该标记的读数可升格为"有功效的探索性读数"，但仍不是确认（数据已消耗）。

## 6. 判读门槛（每个标记 × 每个问题，先于结果）

1. **升级候选**：预期方向 ∧ 量级 ≥ SESOI ∧ |t_NW| ≥ 2.0 ∧ 同向折数 ≥ 8/11（或 ≥ 73% 的有效折）。
2. **方向性支持、不可判读**：量级 ≥ SESOI 但 t 或一致性未达；或 t 与一致性达标但量级 < SESOI。
3. **方向性不利**：反方向 ∧ |t| ≥ 2.0 ∧ 反向折数 ≥ 8/11。
4. **无信息（在该 MDE 下）**：其余。

多重比较：12 个标记 × (Q1 + Q2b) = 24 个门槛检验，零假设下 |t| ≥ 2 的期望命中 ≈ 1.2 个。
另报 Bonferroni 口径（|t| ≥ 2.87）的命中数。**单个「升级候选」若无 Bonferroni 支撑，
记为"与零假设相容的单次命中"**，仍可作为候选，但报告必须写明。

## 7. 禁止事项（CLAUDE.md §一 四类错误的对照）

1. **前视**：任何特征只用 ≤ t 日 K 线；`label` 只出现在 `y` 的构造里。提交前 `grep -n label` 逐处核对。
2. **在评估窗选参**：L、k、ATR 窗、有效期、回看根数**一律不改**；不跑变体；不按结果挑标记子集。
3. **只有量级没有一致性**：门槛已含同向折数。
4. **时点**：标签本身已是 t+1 开盘建仓；标记必须在 t 收盘可算。
