## 3. 功效声明（诚实）

按 `CLAUDE.md` §二强制要求，三样一起写下。**§3.1–§3.3 的数字相对 v1 完全不变**；
只有 §3.4 的措辞按 09-03 裁定改写。

### 3.1 SESOI

**SESOI = IC₂ ≥ 0.0085**（6 日标签、top500 口径）。

来源不是主观：它是**稀释门槛**——等权秩相加要不损害信号#1，
需 `IC₂ > IC₁ × (√(2(1+ρ₁₂)) − 1)`（调研 B 式(2)），
代入 `IC₁ = 0.0155`（0.0207 打 25% 赢家诅咒折价）、`ρ₁₂ = 0.2` 得 **0.008513**。
低于它，加信号#2 在等权规则下是负增益，**不值得据以决策**——这正是 SESOI 的定义。

> **v2 补注（不改数字）**：0.0085 在 v2 里**不再是任何判据的阈值**（§4 已删去全部 IC 量级门）。
> 它在本节保留的唯一作用，是让 §3.4 的功效关能够被计算出来——即回答
> 「我们本来想检出的那个效应量，本样本量能不能检出」。它在 §7 披露里作为**参考数字**出现。

### 3.2 预期效应

调研 A 推断隔夜/日内分解的**月频 IC 约 0.02–0.03**（该推断本身标注为「大盘股子样本量级未核到」）。
按 `IC_h ∝ √h` 换到 6 日标签：`√(6/21) = 0.5345`

```
0.020 × 0.5345 = 0.0107
0.030 × 0.5345 = 0.0160
```

**预期 IC₂（6 日标签）= 0.010–0.016。**

### 3.3 SE 与 MDE

Kronos 在同一 832 天上的 NW 标准误：`SE₁ = 0.0207 / 3.63 = 0.0057`（`HANDOFF.md` §2）。
信号#2 是慢信号，`score(t)` 的 21 日重叠窗使逐日 IC 的自相关**高于** Kronos，
NW 长期方差随之抬高。取 **1.0–1.5×**：

```
SE₂ ∈ [0.0057, 0.0086]
MDE80 = 2.8016 × SE₂ ∈ [0.016, 0.024]        （双侧 α=0.05，功效 80%，Z = 1.96 + 0.8416）
```

**目标功效：80%。**

在预期效应处的实际功效（由 §3.2、§3.3 的数直接算出，非新假设）：

| 效应 | SE=0.0057 | SE=0.0086 |
|---|---|---|
| 0.010 | 41% | 20% |
| 0.013 | 63% | 33% |
| 0.016 | 80% | 48% |

### 3.4 判定：不是确认性检验，是准入检查

```
MDE80 / SESOI = 0.016/0.0085 … 0.024/0.0085 = 1.9 … 2.8   → 全部 > 1
MDE80 的下界 0.016 = 预期效应的上界 0.016                  → 最乐观处也只有 80%，一般情形远低
```

**结论（措辞按 `CLAUDE.md` §二强制格式）**：

> **「信号#2 vs 零」在开发折 36–42 上不构成确认性检验。在本样本量下该问题不可回答。**

由此推出 v2 的措辞裁定：

> **§4 的读数是一次「准入检查」（B 层资源分配），不构成对信号#2 的确认，也不构成对它的否定。**

两条强制措辞，任何后续引用必须照写：


### 4.3 这道门有多松（本文件推导，先于数据写下）

零效应（真实 IC₂ = 0）下，符号门单独的通过率是 **0.5**；
`k⁺ ≥ 4`（7 折二项、每折 p=0.5）的通过率是 `P(Bin(7,0.5) ≥ 4) = 64/128 = 0.5`（精确值）。
两者由**同一批数据**算出、强正相关，因此联合通过率**远高于**独立情形的 0.25，
量级上约 **0.4–0.5**（标为**推断**：未算折间相关的具体结构）。ρ 门与效应量近似独立。

**即：这道准入检查在零效应下也有约四成到五成的概率放行。** 这不是缺陷，是 §3.4 的直接后果——
本样本量下不存在既有功效又不违反 `CLAUDE.md` §二的量级门。**把关很弱这件事必须原样披露**
（§7 第 6 条），并且它正是「IC₂≈0 时秩相加指数掉到 57」这一最大单点风险的实际暴露口。

## 4a. 合成规则（已裁定，不由数据选）

**依据**：ledger 2026-09-03 `DECISION | 信号#2 合成规则按 B 层先验定为「逐日等权秩相加」`
（用户将策略判断委托助手作出；**决定在信号#2 任何真实读数之前作出**）。
分析依据为 `docs/调研_合成规则专项_2026-09-03.md`。

### 4a.1 规则

```
score_combo(t, i) = mean( pct_rank_t(score_kronos)[i] , pct_rank_t(score_signal2)[i] )
                  = 0.5 × pct_rank_t(score_kronos)[i] + 0.5 × pct_rank_t(score_signal2)[i]
```

- **逐日重算**；`pct_rank` 为当日截面百分位秩（pandas `rank(pct=True)`，并列取平均秩），
  取值落在 (0, 1]。
- 权重 0.5 / 0.5 是**上游默认 1/N**，是**预注册常数，不是拟合出来的**。
- **零新自由参数。**

**缺失 / 陈旧的处理（写死，这是第 4 个隐性参数，必须先验固定）**：

```
信号#2 在名字 i 于日 t 上「有效」 ⟺ score(t) 非 NaN（§1 的 MIN_VALID / MAX_SPAN_DAYS 已满足）
                                   ∧ 最近一次有效值距 signal_date 不超过 31 个日历日
否则：score_combo(t, i) = pct_rank_t(score_kronos)[i]            （= Kronos 单臂分）
```

### 4a.2 名字集的字面口径（为使规则可执行所作的细化）

- `N_t` = 当日按滞后 ADV20 排名前 500、且有 Kronos 分数的名字（**现状口径，不动**）。
- `V_t` ⊆ `N_t` = 其中信号#2 按上式**有效**的名字。
- `pct_rank_t(score_kronos)` 在 **`N_t`** 上算（全体名字同一把尺）。
- `pct_rank_t(score_signal2)` 在 **`V_t`** 上算。
- `i ∈ V_t`：`score_combo = 0.5 × (rk_kronos^{N_t}[i] + rk_signal2^{V_t}[i])`；
  `i ∈ N_t \ V_t`：`score_combo = rk_kronos^{N_t}[i]`。

两条性质（写下来是为了让这个细化可被核对）：

1. `V_t = N_t`（无缺失）时，本式**退化为** `src/portfolio/combine.rank_sum_equal_weight`
   的现有语义（「先取交集再排秩、0.5×(ra+rb)」）——即它是既有冻结实现的严格推广。
2. 缺失/陈旧的名字被记为「**信号#2 恰好与 Kronos 的百分位秩一致**」的中性处理，
   既不因缺失被驱逐出可持有集，也不因缺失获得排名优势。

> **披露**：§4a.2 这一层（哪个秩在哪个名字集上算）在 09-03 的裁定原文里未逐字规定，
> 是本文件为使规则**可机械执行**而作的字面细化，属**披露的实现选择**。
> 若与用户意图不符，须在登记（§0 前置条件 ③）之前更正；登记之后按字面执行，不得事后改。

### 4a.3 其余构造一律不动

`top500` 池、进前 **10%**、跌出前 **30%**、`NT=5`、等权、`t` 收盘算分 / `t+1` 开盘成交
——**全部沿用 Kronos 单臂的冻结构造，一个字不改**
（`NT=5` 为 ledger 2026-09-03 `ablation-read` 起的现行冻结构造；`HANDOFF.md` §2 的 NT=6
读数表保留为历史）。合成只换「排名用哪个分数」，不换「怎么用排名」。
理由：`CLAUDE.md` §五「组合构造必须先冻结再比臂」。

### 4a.4 裁定依据

按 `CLAUDE.md` §二 B 层优先序，四条里**三条指向逐日等权秩相加 (a)**：

| | ① 上游默认 | ② 自由参数最少 | ③ 算力/成本最低 | ④ 对机制变化最稳健 |
|---|---|---|---|---|
| **(a) 秩相加** | **✅ 明确** | **✅ 0 个新参数** | **✅ 换手 −23~33%** | ⚠️ IC₂→0 时指数掉到 56.6 |
| (b) 慢信号筛子 | ⚠️ 部分 | ❌ ≥3 个新参数 | ❌ 换手 **+20~38%** | ✅ IC₂→0 时指数 75.4 |
| (c) meta-labeling | ❌ | ❌ 需训练二级模型 | ✅ 换手 −60% | ❌ IC₂→0 时指数 0 |

- **①**：1/N 的上游默认有三条硬证据——DeMiguel-Garlappi-Uppal (2009, RFS) 在 7 组数据、
  14 种优化模型下无一稳定击败 1/N；因子投资的标准做法就是等权 z-score/秩平均；
  Grinold (2010, JPM) 的最优权重 `Σ⁻¹IC` 在 ρ 小、IC 接近时数值上贴近等权。
  **条件双重排序不是上游默认**（Fama-French 经典 2×3 是独立排序）。
- **②**：(a) 的 `mean(rank, rank)` 不引入任何常数；(b) 需定 `keep_frac`、持有筛还是准入筛、
  以及 10%/30% 套袖在缩小后的可持有集里如何重定——**至少 3 个新参数**，且最优 `keep_frac`
  依赖未知的 IC₂ 与 ρ，先验定不出来。
- **③**：**筛子不是不增加换手，是增加 20–38%**（慢信号的中位数线是一条会被反复穿越的边界，
  21 日滚动和的日度中位数穿越率约 9.9%）。(a) 反向：合成分自相关 `a_c ≈ 0.828`，
  换手 **−23% ~ −33%**。有一手文献直接背书：DeMiguel 等 (2020, RFS)——
  组合多个特征会**降低**交易成本，因为不同特征要求的调仓在个股层面相互抵消。
- **④ 是唯一反向票**，按 `CLAUDE.md` §二「**B 层平局（2026-09-03 用户裁定）**」条款以
  **minimax-regret** 破局。

**minimax-regret 破局（后悔以「占现状净超额的百分比」计，候选集含「不合成」）**：

| 5 bp | **21.2** | 22.4 | 71.2 | 29.5 | (a)（勉强） |

2003–04 那一段 BE 仅 3.4bp（`HANDOFF.md` A.1，成本敏感性是本策略最大脆弱点）、

**取 (a)，最大后悔 = 现状净超额的 20%。**

**(c) 另有一条独立的出局理由**：在 `CLAUDE.md` 冻结的构造下（只做多 → 方向恒为 +1；

**都被堵死**，它只剩「降低总仓位持现金」这一条择时通道，而项目没有任何择时证据。
