# moomoo 持仓管理规则 v0.1(草案)

**状态**:参数(【】内)待本人确认后生效。生效后规则即合同,改规则只能在月度复查日改,不能在盘中改。
**适用**:moomoo 美股账户的 6 只存量持仓。标普底仓不适用本规则(它是底仓,永远不动)。
**目标(诚实版)**:目标线 = 账户净值(持仓市值 + 现金)回到 **$4000**。本规则不承诺回本;它做两件事——堵住继续瞎操作的亏损,并让剩余资金以最高概率向目标线移动。**账户回本 ≠ 每只票回本**:一只票该不该继续持有,只取决于它今天值不值得持有,与成本价无关。

---

## 规则 0:成本价禁入决策

任何持有/卖出决定,禁止以"我的成本是多少"作为理由。成本价只在报税时有意义。
每月复查只问一个问题:**「如果我今天空仓,会按现价买它吗?」** 会 → 继续持有;不会 → 它占用的钱应该去别处。

## 规则 1:灾难止损(服务器端条件单,拉长线的底线)

- 每只持仓挂一张长期有效的止损条件单,触发价 = 当前价 × (1 − 【25%】)。
- 这不是日常操作工具,是"论点被证伪"的灾难线——宽到日常震荡碰不到,才不会重演被反复打脸的旧剧本。
- 触发卖出后 **30 天冷静期**,期间禁止回补同一只票。
- 每次月度复查后,若某票较上次复查价上涨 ≥【15%】,把该票止损价上移到 新价 × (1 − 25%)(只上移,永不下移)。

## 规则 2:月度复查(唯一的主动决策窗口)

- 时间:每月第一个【周六】(美股闭市,强制冷静)。
- 每只票过一遍规则 0 的问题,写一行结论和理由。
- **模型信号作复查输入(策略上线后生效)**:Kronos 策略上线后,每次复查附上模型对这 6 只票的横截面排名分位(在 universe 内的话)。排名是规则 0 检验的数据输入之一,不是自动指令。
- **连续两次**复查不通过 → 下一个交易日卖出【50% / 全部】,不再讨论。
- 复查之外的所有日子:不看不动。条件单在服务器上值班,不需要你。

## 规则 3:时间止损

- 自本规则生效起,任何一只票【9】个月后仍未通过过一次"今天会买"检验 → 无条件离场。
- 作用:防止"套着就一直拿着"把 −30% 拖成 −70%。拉长线是给论点成立的票的,不是给不想面对的票的。

## 规则 4:禁止行为清单

1. 禁止给亏损仓位加仓(摊平 = 把更多钱交给已经错了的判断);
2. 禁止盘中临时决定(所有决定只在复查日做,条件单触发除外);
3. 禁止因当天新闻当天行动——写进下次复查议题;
4. 禁止在复查日之外修改任何条件单;
5. 禁止用这 6 只以外的新票"博一把捞回来"。

## 规则 5:卖出资金的去向(预先指定,不临场决定)

任何卖出(止损/复查/时间止损)所得,默认转入:【标普底仓 / 现金,二选一预先写死】。
不允许"先放着看看有什么机会"——那是瞎操作的入口。
**例外(数据接管条款)**:Kronos 策略通过 §7.5 双层评估后,本条默认去向可改为策略户(Alpaca)——即这笔钱最终交给模型管理。在那之前不允许,因为未通过验证的模型不是数据,是披着代码的情绪。

## 规则 6:到达目标线后的动作(预承诺)

账户净值连续【5】个交易日 ≥ $4000 → 执行预定动作:【a. 清仓全部 6 只,资金转底仓;b. 只保留当月复查通过的票】。
现在选好 a 或 b 写死。到时候执行,不重新讨论——"到了目标又想再等等"和"套牢死扛"是同一个错误的两张脸。

## 规则 7:日志

每笔操作记一行:日期 / 票 / 动作 / 触发的规则编号。月度复查结论存档。
这是复盘的唯一依据,也是将来判断"这套规则本身要不要改"的唯一证据。
