# 训练池与模型规模：证据调研（2026-08-27）

> 执行：Claude (Opus agent)，web 检索核实。触发问题：微调用未过滤全量面板
> （约 81% 行来自非 universe 股票）是否会对 universe 内打分产生负迁移；
> 底模 small vs base。结论先行：**证据天平偏向流动子集训练**；base 留作
> 后置消融且不应 full fine-tune。决定记录见文末与 experiments/ledger.md。

## 核心证据（按说服力排序）

1. **Kronos 作者自己在预训练时就过滤了低流动性 K 线**（论文 Appendix B：
   illiquidity filtering 连续零/近零成交量 bar、price stagnation、结构跳变
   分段；原话 "The integrity of large-scale pre-training is contingent upon
   high-quality input data"）。全量微调等于把作者当污染滤掉的数据放回来。
2. **官方微调 demo 的池子 = 打分池**（CSI300，A 股最流动的 300 只；论文
   回测也只在 CSI300/CSI800 上做）。官方实践即"微调池与打分池同分布"。
3. **"数据多防过拟合"在本管线配置下几乎不成立**：每 epoch 只抽 10 万样本，
   占全量池 260 万窗口的 3.8%，30 epoch 只遍历约 1.15 遍——真正被消费的是
   **采样分布**而非池子大小。改流动子集后池子仍有 ~50 万窗口（每 epoch 采样
   量的 5 倍），数据饥饿不构成约束；代价是遍历升到 ~6 遍，早停必须盯紧。
4. **Howard (2023, SSRN 4497739)**：唯一直接做"训练池"消融的资产定价 ML
   论文——按市值分组训练显著优于全池训练（ensemble 年化 20.0%→31.8%），
   机制是全池模型过拟合到小盘收益。本管线的 token CE + per-window z-score
   切断了"方差主导"路径，但"分布主导梯度"路径同向存在。
5. **TAPT 逻辑**（Gururangan 2020 及 TSFM 负迁移文献 arXiv 2607.23146 等）：
   一般动力学已由预训练（45 交易所、12B K 线）提供，微调的边际价值就是
   分布适配；固定算力下池子组成 = 梯度预算分配（FineWeb-Edu 同向定量证据）。
6. 微观结构机制：z-score 消掉价格量级但消不掉**形状**——价差弹跳的负一阶
   自相关（Roll 1984）、停牌重复价、低价股价格网格。这些保留在 token 序列里。

## 消融设计建议（agent 原文要点）

- 三臂：**A** 全量（现状）/ **B** universe-only anchor（point-in-time，禁用
  未来成员资格）/ **C** 全量 + Kronos Appendix B 式软过滤（零量 bar、价格
  停滞、结构跳变；不做市值硬切）。C≈B → 问题是数据质量；B>C → 是分布匹配。
- **主判据不要用验证 token loss**（天然偏向 A，验证分布与 A 同源）：用
  universe 内逐日横截面 RankIC 均值 + Newey-West t，外加**市值/ADV 五分位
  分层 IC**（核心假设"B 在大市值层 IC 更高"若不成立即证伪负迁移）。
- 组合层看价值加权 top-decile 多空、成本后净收益；稳定性看折间 IC 方差与
  利润集中度；评估日凑 200+ 个否则读不出差异。

## 模型规模 small vs base

- 论文只有图形化"随规模单调变好"（Figure 1/4），**无公开数值表**；头条
  数字来自未开源的 large。社区零定量对照（Issue #375 只测了 small）。
- 同量级反证：Chronos-2（120M）full fine-tune 在多数设置**持续退化**
  （arXiv 2607.23146）；紧凑模型（1–36M）full FT 合适。
- 16GB 卡 + 官方纯 fp32 脚本（无 AMP/无梯度检查点/累积未接线）跑 base
  batch 50 估算需 13–17 GB，**大概率 OOM**；要跑需 bf16 autocast + 梯度
  累积，且建议 LoRA 而非 full FT。
- **结论：base 排在池子消融之后，优先级低**——zero-shot 美股 IC 仅 +0.022
  的信噪比下，分布对齐的预期收益远大于模型容量。

## 必须记录的三个外部事实

1. **Issue #375**（唯一美股横截面定量报告，small zero-shot，182 股，85 个
   调仓日）：IC +0.022，NW t=1.39 不显著；扣 10bp/边后多空年化 +7.2%
   （SR 0.35, t=0.69）**成本后不成立**；利润高度集中（前 5 天贡献 91%）。
   → 这是本项目的 zero-shot 基线预期，微调的增益要拿它对照。
2. **Issue #307/#227**：官方 finetune dataset 曾有归一化泄漏 bug（mean/std
   误用全窗口），代码已修复（本仓库用的当前版无泄漏），**但 HF 上的预训练
   checkpoint 是否在修复后重训过，官方未回复**——small/base 同等适用的
   未决疑点，不影响我们内部 A/B 的公平性。
3. **采样路径 spread 比实际窄约 2.7 倍**（#375 校准报告）：多路径均值可用，
   但路径分布不可直接当不确定性/风险度量。
