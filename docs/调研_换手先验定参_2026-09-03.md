# 降低换手的构造规则：文献与解析证据（2026-09-03，Claude opus agent，web 调研 + 自行推导）

> 触发问题：年单边换手约 48×、breakeven 21.9bp、真实成本未测。能否在**不重新在开发折上搜索**的前提下，用先验/文献/解析固定的规则把换手降下来。
> 待证伪假设 H_C：「对半衰期约 2 日的信号，任何把换手降 30% 以上的构造规则都会损失 25% 以上的毛 alpha；且这类规则的参数无法按先验固定，必须在数据上调。」
> **注意**：agent 在主会话桌面端闪退时丢失了部分并行文献核对子流，正文中的具体数字采信前应回原文核对；定性结论与解析推导置信度高。全程未运行 python、未碰 GPU、未读 outputs/；只读了 `scripts/optimal_holding.py` 的 docstring 对齐术语。

## 结论先行

**H_C 被部分证伪。**

- **第二分句（「参数无法先验固定，必须在数据上调」）被明确证伪。** Gârleanu-Pedersen (2013) 命题 2 明确指出最优交易速率 `a/λ` 只依赖风险厌恶 γ、成本参数 λ、贴现率 ρ，**与 alpha 信号本身无关**；比例成本下无交易带宽有 `δ = O(ε^(1/3))` 的标度律（Constantinides 1986 / Davis-Norman 1990 / Shreve-Soner 1994）；而本项目的退出线还能直接由**已测的分数信度 0.75** 解析反推。三条路都不需要在收益上搜。
- **第一分句（「>30% 换手削减必损 >25% 毛 alpha」）在单信号现状下大致成立，但在多信号路径上被证伪。** DeMiguel 等 (2020) 的 trading diversification 是「换手大降 + alpha 不降」的反例。

**最推荐的一条规则：不要再动单信号的进入/退出线（下证 30% 已落在先验区间的正中），把 48× 换手的削减留给信号#2。** 若必须在单信号内动，把退出线写成成本 c 的函数（边际互换不等式），而不是常数。

## 1. GP「aim in front of the target」——能否先验固定？能，但模型类不匹配

**有文献证据。** GP 2013 的解为：`x_t = (1 − a/λ)·x_{t−1} + (a/λ)·aim_t`（命题 2），交易速率 `a/λ` 关于 λ 递减、关于 γ 递增，**且独立于当前持仓与信号取值**。命题 4 给出 aim 组合中第 k 个因子被按衰减速度缩放：`aim_t = (γΣ)^(-1) B [ f_1/(1+φ_1 a/γ), …, f_K/(1+φ_K a/γ) ]'`。所以参数确实可由 (γ, λ, ρ, φ) 闭式给出，**不需要收益搜索**——这一点足以证伪 H_C 第二分句。

**关键否定性发现（推断）：这套规则对本项目不适用。** GP 假设 **二次（价格冲击型）成本** `Λ = λΣ`。本项目每笔名义额 = AUM/300，标的在 ADV 前 500，MOO 成交，参与率量级 1e-4——成本几乎纯粹是**比例成本**（点差 + $0.004/股 ≈ 0.9bp），λ 在数据上**不可识别**。在比例成本下最优策略不是「每期部分成交」，而是**无交易带 + 只交易到带边**（Constantinides 1986；Davis-Norman 1990）。也就是说：本项目现行的 10%/30% buy/hold spread **就已经是**这个模型类下的正确解形式，GP 的部分成交不是增量。

另一个纯解析要点（推断）：**单信号时 GP 命题 4 的 `1/(1+φ a/γ)` 缩放对本策略完全无效**——它对所有股票是同一个标量，只改变总敞口（杠杆），不改变横截面相对权重，因此不改变任何一笔换手。φ 加权只有在**多个衰减速度不同的信号**并存时才产生构造影响。这正好把答案推向第 3 节。

Jensen-Kelly-Malamud-Pedersen (RFS 2026) 是这套框架 + ML 信号的实证版：不计成本的 Markowitz-ML 毛 Sharpe 约 2.0 但净收益为负；成本感知的 Portfolio-ML 毛 Sharpe 降到约 1.43、净 1.38，换手降两个量级。**有文献证据**：他们明确指出成本会把权重推向**自相关高的特征**（book-to-market 0.94、momentum 0.87），而短期反转（自相关 −0.04）「摧毁掉几乎不改变可实现前沿」。这对一个半衰期 2 日的信号是个警告，也是加慢信号的直接论据。

## 2. Novy-Marx-Velikov 三法：第三种对本项目无增量

**有文献证据（数字自 NBER w20721 正文提取）：**

| 技术 | 参数 | 换手降幅 | 成本降幅 |
|---|---|---|---|
| buy/hold spread（sS 规则） | 中换手 10%/20%；高换手 10%/50% | 约 41% | 约 42% |
| 错位/降频再平衡 | 频率降到约 1/3 | 约 1/3 | 约 1/3 |
| 限制低成本股票池 | 各规模十分位内成本最低 1/3 | — | 高换手组约 25% |
| 三者合用 | — | 约 60% | 约 59% |

NMV 的结论是 buy/hold spread 是「单一最有效的简单缓解手段」；但对**高换手策略**，季度错位「不足以维持因子暴露」，必须三法合用。注意他们对高换手用的是 **10%/50%**，比本项目的 10%/30% 宽得多。

**关于第三种（对整个组合权重变动设带宽）：推断是本项目增量接近零。** NMV 的 banding 是在**排序变量**维度（即 sS 规则），本项目已在用。若把带宽加到**权重**维度：本策略是 ~50 只等权、6 档错位，权重不来自优化器，只在名字进出时跳变，日内权重漂移不足 1%——权重带宽根本不会被触发，只会拦掉本就不做的微调交易。真正的换手全部来自名字进出，只有排序维度的带宽才管用。

## 3. DeMiguel 等 (2020)：唯一能同时降换手且不损 alpha 的路径

**有文献证据。** 论文原文：「单独利用一个特征所需的月均换手是 **24.09%**，而等权组合这些特征所需的换手只有 **6.71%**；即 trading diversification 带来 **72.15%** 的换手削减」；在最优组合中，「15 个显著特征的**边际交易成本平均下降约 65%**」。机制是不同特征要求的个股交易**相互抵消**。也正因如此，考虑成本后**联合显著的特征数从 6 个升到 15 个**——成本是纳入更多特征的经济理由，不是减少特征的理由。

**推断（对本项目的量化外推）：** 上述 72% 是 15 个特征、且多为慢特征（自相关接近 1）的结果，不能直接搬到「1 快 + 1 慢」。做 50/50 融合、慢信号自身换手近零时：融合分数的日度变动幅度约为原来的一半，但换手是**穿越阈值的概率**而非幅度，非线性。合理区间是**单边换手降 30–45%**（48× → 26–34×）。同时快信号在组合分数中的权重减半，但慢信号自己带 alpha 进来——所以这是**替换**而非**损失**毛 alpha。这就是 H_C 第一分句的反例：换手降 >30%，毛 alpha 不必降 25%。

**代价（推断）：** 融合权重本身是一个新参数。要避免在开发折上搜，权重必须用先验固定——推荐 **IC 加权 / 风险预算等权**（w_i ∝ IC_i/σ_i，两个信号的 IC 各自在**各自的**样本上单独测得，不看组合收益），或直接 50/50。这两种都不消耗评估折自由度。

## 4. 用分数信度反推带宽 δ：本报告最硬的一条结果

**推断（方法有文献先例，数字是本项目的）：** 经典测验理论下，两次重打分的相关 r = σ_T²/(σ_T²+σ_E²)。r = 0.75 ⟹ 在标准化分数（总 SD = 1）中，**噪声 SD σ_E = √(1−0.75) = 0.50**。这是个很大的噪声：分数一半的标准差是重打分噪声。

一个名字的排名下滑是否「真的」下滑，标准判据是它超过**两次独立打分之差的标准差** `√2·σ_E = 0.707`。于是：

```
z_entry = Φ⁻¹(1 − 0.10) = 1.2816
z_exit  = z_entry − √2·σ_E = 1.2816 − 0.7071 = 0.5745
q_exit  = 1 − Φ(0.5745) = 28.3%
```

**现行的 30% 退出线 = 28.3% 的先验值，误差在四舍五入内。** 换个 δ 的取法也落在同一区间：δ = 1σ_E → 21.7%；δ = 1.5σ_E → 29.7%；δ = 2σ_E → 38.9%。

**结论：10%/30% 这一对不是在噪声上搜出来的偶然值，它就是「秩变动超过一次重打分噪声」这个先验判据的解。** 这可以如实写进设计文档，把这个参数从「折上搜索」重新归类为「先验固定」。反过来，这也说明**在信度 0.75 下没有先验理由把退出线推到 40% 以上**——那已经超出 2σ_E。

比例成本文献给的是另一条独立标度律 `δ ∝ ε^(1/3)`（**有文献证据**：Constantinides 1986；Davis-Norman 1990；Shreve-Soner 1994 给出带宽 O(ε^(1/3))、效用损失 O(ε^(2/3))）。它给的是**相对**关系而非绝对值，用途是：一旦实测成本 c 比假设值高 k 倍，带宽应按 **k^(1/3)** 加宽——例如成本翻倍，带宽只加宽 26%，对应退出线 28.3% → 约 33%。这是极强的约束：**成本的不确定性几乎不改变最优带宽。**

## 5. 时序：先测成本，且不要跑两套订单流

**有文献证据（实务方向）：** Frazzini-Israel-Moskowitz (2018) 的做法是用 19 年、1.7 万亿美元的**实际成交数据**先拟合成本函数（关于交易规模、点差、波动、ADV、市场的函数），再把它当作 pre-trade 模型放进组合构造。方向是「先测、再优化、再迭代」，而不是先定构造再测。Bojinov-Shephard (JASA 2019) 提供了在**活体交易中做随机化实验**的正式框架（AHL Partners 实盘案例），随机化在**订单层面**做 i.i.d. Bernoulli 分配，并用精确随机化检验处理时序相依。

**推断（对本项目的具体建议，与「奇偶日交替」相反）：**

1. **不要做双订单流试验。** 在 ADV-500 + AUM/300 + MOO 的条件下，成本 ≈ 点差 + 佣金，对**订单条数**近乎不敏感；带宽变更改变的是每天下几单，不改变单笔规模、场所、标的流动性档位。两套订单流的成本差异本就接近零，花一半统计资本去测它是浪费。
2. **正确做法是「一套订单流 + 协变量成本模型」。** 用**现行构造**下单，逐笔记录 fill、官方开盘价、开盘前点差、ADV20、名义额、方向、当日波动；然后拟合 slippage ~ f(点差, 名义额/ADV, 波动, 方向)。有了这个函数，**任何反事实订单流的成本都能解析定价**，不需要真的去跑它。这正是 FIM 2018 的做法。
3. **统计资本估算（推断）：** 现行每天约 9–10 个卖出 + 9–10 个买入 ≈ 19 笔，40 个交易日约 760 笔。若单笔 slippage 的 SD 为 30–60bp，均值的标准误约 1.1–2.2bp。相对 21.9bp 的 breakeven，这足够判定「成本是否显著低于 breakeven」。若拆成奇偶日两臂，每臂 SE 升到 1.5–3bp，**差值**的 SE 3–4bp——要检出 5bp 以内的订单流差异需要 3–4 倍的天数。不值得。
4. **随机化实验留给真正的执行学问题**（MOO vs. limit-on-open、不同 router、不同下单时点），那时按 Bojinov-Shephard 在**订单层面**随机化，不要按天。

**顺序建议：** 先跑 30–60 日实测 → 得到 c 与成本函数 → 用 c 重算 `T*(c)` 与 `q_exit(c)` → 只有当实测 c 显著高于当初 T*=3–5 计算里的假设值时，才按 `k^(1/3)` 加宽带宽。**构造变更由成本触发，不由收益触发。**

## 6. 10% / 30% 本身的先验支持

**推断，三条独立论证同向：**

- **信度论证（第 4 节）**：退出线 28.3%，与 30% 一致。
- **持仓期论证**：退出线与持仓期是同一个参数的两种写法——退出线越宽，名字平均在册时间越长。项目已解析求得 `T* = 3–5 日`，而现行 30% 对应的实际持仓约 6 日，**已经在解析最优的上沿甚至之外**。这意味着在当前成本假设下，**再放宽退出线是朝远离解析最优的方向走**，H_C 第一分句在单信号情形下因此基本成立。
- **进入线 10%**：它不是收益搜索的产物，而是被**账面股票数**机械钉死的——500 × 10% = 50 只，正是等权 50 只的目标。分散化文献的常识是边际分散收益在 30–50 只上基本用尽。所以进入线的先验来自风险，不来自收益。

**由此得到唯一的「参数写成成本的函数」型规则（推断，推荐作为唯一改动）：**

设 `R(q)` 为分数分位 q 的名字未来 6 日相对池均值的超额（与 `e(h)` 同类的机械原语，不看组合收益）。每档再平衡时，把一个已跌到分位 `q_h` 的持仓换成分位 0.10 的新名字，剩余持有期 H 内的期望增益为

```
G(q_h) = Σ_{h=1..H} [ e_new(h) − e_hold(h; q_h) ]
```

**仅当 `G(q_h) > 2c`**（卖一笔 + 买一笔 = 两个单边成本）才交易。退出线 `q*` 由 `G(q*) = 2c` 解出。

这条规则的性质：(a) 与现行 buy/hold spread 是**同一函数族**，`q*=30%` 只是 `c = c₀` 时的特解，不改变订单流类别；(b) 参数完全由已测原语 + 外生 c 决定，**不消耗评估折自由度**；(c) 逐档报告 `q*(c)`，与 `optimal_holding.py` 已有的「逐档 bp 报告」纪律一致。
