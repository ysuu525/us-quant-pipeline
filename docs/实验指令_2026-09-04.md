## 实验 0：CRSP `DlyOpen` 缺失率与口径核查（CPU，约 30 分钟）

**背景**：用户文献综述核实 CRSP 文档称 `DlyOpen` = 开盘后**首笔成交**（非竞价印价），且仅 60% 非缺失、覆盖 77% 证券。本项目的建仓价 = `t+1` 的 `DlyOpen`（`src/crsp_pipeline/labels.py:118-128`），若在 top500 里缺失率高，标签口径与小试基准都要复核。

**判据**：诊断，无阈值。**用途限制**：只报数，不改任何口径。

**步骤**：
1. 新建 `scripts/exp0_dlyopen_coverage.py`。分块（每 2 年）读 `F:\quant\processed\crsp_ciz_2026-08-24_20260825T130601Z\panel_raw.parquet`，列 `[PERMNO, DlyCalDt, DlyOpen, DlyClose, DlyPrcVol]`，`filters` 按 `DlyCalDt` 下推，范围 2000-01-01..2025-12-31。
2. 每块内按 PERMNO 算 `adv20 = DlyPrcVol.rolling(20, min_periods=10).mean().shift(1)`；每日取 adv20 前 500 名 = top500 股票日。
3. 对 top500 股票日按**年**统计：N；`DlyOpen` 为 NaN 的比例；`DlyOpen < 0` 的比例（CRSP 负价 = 买卖中价约定，单独计）；`DlyOpen == 0` 的比例；`|DlyOpen| == |前一日 DlyClose|` 的比例（疑似无成交承接）；`|DlyOpen/前收 − 1| > 20%` 的比例（疑似异常）。另对**全池**同样统计一份。
4. 对折 36–42 的 FT `labels.parquet`（列 `status`）统计每折 `ok / unfillable / invalid` 的占比（这是缺失开盘价在标签层的实际后果）。
5. 输出 `outputs/exp0_dlyopen_coverage.json` + 控制台年度表。

**交回**：两张表（top500 年度、全池年度）+ 折 36–42 的 status 占比 + 草稿行。**若 top500 的 NaN 或 ≤0 比例任何一年 > 2%，在交回时单独标红。**

## 实验 2：分数加权 vs 等权（**盲功效关先行**；CPU，约半天）

**背景**：用户想知道「按分数加权」是否优于等权。文献在纯多个股层面无直接实证。本项目规则：构造变体比较先算 MDE，MDE > SESOI 则 B 层（按先验取等权 = 上游默认 1/N），**不看均值**。K9（2026-08-31）用过同一套盲法。

**判据（先写死）**：
- 配对量 `d_t = r_rank,t − r_equal,t`（FT，折 36–42，NT=5，cost=0，逐日毛超额差）。
- **SESOI = 0.50 bp/日**（= NT=5 毛 12.68%/年 的 10% ÷ 252）。
- **盲阶段**只算 `SE_NW5(d)`、`MDE80 = 2.8016 × SE`、两构造的年单边换手比。**均值必须遮住**（写入 `outputs/exp2_weighting.blind.json` 并在控制台打印 `***`）。
- `MDE80 > SESOI` → 结论「在本样本量下该问题不可回答，按先验取等权（上游默认 1/N）」，**不揭盲，实验结束**。
- `MDE80 ≤ SESOI` → 用 `--unblind` 揭盲：报 mean、NW t、stationary bootstrap 95% CI（块长 10、10000 次、seed 20260904）、7 折中 d 均值 > 0 的折数、换手比。**通过判据**：`t ≥ 1.96` ∧ `≥ 5/7 折同向` ∧ `换手增幅 ≤ 20%` → 记「设计修订候选，待用户裁定」；否则「不采用」。
- **用途限制**：无论结果如何，**执行者不得改动任何冻结构造**；只交回。

**步骤**：
1. 在 `src/portfolio/construction.py` **新增**函数 `frozen_long_only_returns_weighted(..., weighting="equal")`：
   - `weighting="equal"` 时**逐位复现** `frozen_long_only_returns`（写测试 `tests/test_exp2_weighting.py`，合成数据 3 个种子 `np.array_equal`）；
   - `weighting="rank"`：每个套袖选定的 k 只名字内，权重 ∝ 名次分（分数最高 = k，最低 = 1，归一化和为 1；**只做这一种线性名次权重，不扫其它**）；
   - 收益 = 权重加权（新买入名字当日吃 `oc`，其余吃 `ret`，与原函数同）；换手 `turn` 改为该套袖权重变动的 `|Δw|` 之和 / 2（等权时退化为原定义，测试里断言）；成本公式不变 `2×bp×turn/NT`。
   - docstring 写明「本函数仅供实验 2，不是冻结构造」。
2. 新建 `scripts/exp2_weighting_blind_gate.py`：加载同 `nt5_baseline_readout.py`；两构造各跑 7 折；算 `d_t`；默认盲模式；`--unblind` 揭盲。判据原样抄进 docstring。
3. 跑盲模式 → 按判据决定是否揭盲。

**交回**：SE、MDE80、SESOI、是否揭盲；若揭盲则 mean/t/CI/折数/换手比与判据结论；草稿行。

计划书把「岭探针内层选参 +0.01256 vs 事后最优 +0.01951 的差 **+0.0070**」同时当成
「登记簿量化的选择偏差」和「四类错误之一」，构成 double counting；且摘要写 33%、
§8 写 20–28%、登记簿原话只说它是「同类偏差的**参照尺**」，三个口径互相矛盾。
审稿的修法是把它从**披露**升级成**测量**：本项目有别人没有的东西——一份 append-only、
逐条可数的试验登记簿，所以多重检验次数 N **不是猜的**。

**判据 / 用途限制（先写死，原样抄进脚本 docstring）**
- 本实验是**估计交付**，不是检验。没有任何门槛，**不得**据其判定任何假设通过或失败。
- **不得**用它去改 H1/H2/H3 的判据、SESOI 或功效计算（那些另有既定流程）。
- 第 5 步的收缩区间一经写下并登记，**在读取折 05–35 之前不得修订**；解封后只报
  「实现收缩比」以及它落在区间内还是外，**不回头改区间，也不据此改任何假设的结论**。
- 全部输入来自已消耗的开发折与登记簿文本，**不读任何封存产物**。

**步骤**
1. 新建 `scripts/exp6_deflated_sharpe.py`。
2. **数 N（机械计数，不做主观筛选）**：读 `experiments/ledger.md`，按行首正则
   `^- .*\| eval \|` 与 `^- .*\| ablation-read \|` 分别计数，记录各自首末日期，
   并记下本次所用 ledger 的 **sha256 与字节数**（实验 6 与附录的核对必须用同一份）。
   - `N_low` = `| eval |` 条数（自动登记的每次评估运行 = 每次「看了一眼验证窗」）；
   - `N_high` = `| eval |` + `| ablation-read |`（把每次事后读数也算一次有效试验）。
   - **参考值**（2026-09-03 22:38 的 ledger）：eval **81**、ablation-read **52**、
     DECISION **11**。登记簿仍在增长（同日内 DECISION 从 10 变 11），**以运行时实测为准**；
     审稿引用的 "ablation-read 51" 系其成文之后新增，属正常。
3. **Deflated Sharpe**（Bailey & López de Prado 2014, *The Deflated Sharpe Ratio*,
   J. Portfolio Management 40(5)），对象 = FT 开发折 **NT=5 / 8bp 净收益序列**
   （ledger 2026-09-03 `ablation-read`：839 日、净年化 8.25%、波动 9.59%、**夏普 0.86**）：
   - 逐日净收益序列从 `outputs/nt5_baseline_readout.json` 取；若该 JSON 只存汇总不存逐日，
     用 `scripts/nt5_baseline_readout.py` 的加载与构造函数**原样重算**（**不改该脚本**，
     import 或抄逻辑并注明来源行号）。
   - 记 `T` = 观测日数、`SR_d` = 逐日夏普、`γ3` 偏度、`γ4` 峰度（都用实测，不用年化反推）。
   - 期望最大夏普
     `SR0 = sqrt(Var(SR_n)) × [ (1−γ)·Z⁻¹(1 − 1/N) + γ·Z⁻¹(1 − 1/(N·e)) ]`，
     `γ = 0.5772156649`（Euler–Mascheroni），`Z⁻¹` = 标准正态分位。
   - `DSR = Z[ (SR_d − SR0)·√(T−1) / sqrt(1 − γ3·SR_d + (γ4−1)/4·SR_d²) ]`。
   - `Var(SR_n)`（跨试验的夏普方差）**优先**用登记簿里可提取的同族试验年化夏普的样本方差，
     并把用到的条目行号列出；若可提取条目 < 5 条，退回解析替代
     `Var(SR_n) ≈ (1 + SR_d²/2)/T`，**并在交回里显式标注这是替代口径、会低估 SR0**。
   - 对 `N ∈ {N_low, N_high}` 各算一遍，报 `SR0`、`DSR`，以及**「使 DSR 仍 ≥ 0.95 所能承受的
     最大 N」**（这一条比 DSR 本身更好读：它直接说「这个读数还经得起几次试验」）。
4. **Harvey–Liu haircut**（Harvey & Liu 2015, *Backtesting*, JPM 42(1)；三种多重检验
   调整照 Harvey–Liu–Zhu 2016 RFS：Bonferroni / Holm / BHY，BHY 的 `c(N)=Σ_{i=1..N} 1/i`）：
   - **夏普端**：`t = SR_年化 × √年数`（839/252 = 3.329 年 → t ≈ 1.57，以实测为准）；
     三种调整分别求调整后 p → 反解调整后 t → `haircut = 1 − t_adj/t`；
     报三档 haircut 与 haircut 后的夏普。
   - **IC 端**：口径 = FT / lb90 / sc=5 / **全池** / 折 36–42 合并逐日 RankIC
     **+0.0206679591**（ledger:185/186 的聚合口径）；t 从登记簿抄（**不重算**；
     登记簿若无该 t 则重算并在交回注明「t 系本次重算」）；同样出三档 haircut 与 haircut 后 IC。
5. **写下带区间的预注册点预测（本实验的主交付）**：
   - 预测对象定义死：**折 05–35 上、与 +0.0207 同口径（FT 臂 / lb90 / sc=5 / 全池 /
     逐日 RankIC 合并均值）的点估计**。口径任何一项不同都不算兑现。
   - 中心点 = `0.0207 × 0.75 = 0.0155`（0.75 = 项目既有的对抗性复核折价，`HANDOFF.md:141`
     「20–28%」，全项目运算统一 ×0.75）。
   - 区间由第 4 步 **IC 端**三档 haircut 张成：下界 = 最严（Bonferroni）haircut 后 IC，
     上界 = 最松（BHY）haircut 后 IC。
   - **兜底规则（预先写下）**：若三档全部落在 0.0155 的同一侧，区间取
     `[min(三档, 0.0155) − 0.0027, max(三档, 0.0155) + 0.0027]`，
     `0.0027` = 树基线三种子 SD（ledger:186），作为「同一读数在无关随机性下的抖动」量级参照。
   - 该区间与其推导过程整段写进登记簿草稿行，**解封前登记**。
6. 输出 `outputs/exp6_deflated_sharpe.json` + 控制台表。

**交回**：ledger 的 sha256 与 N_low / N_high 及首末日期；`SR0` / `DSR` /「可承受的最大 N」
（两档 N 各一组）；夏普端与 IC 端各三档 haircut；预注册区间的上下界、兜底规则是否触发；
`Var(SR_n)` 用的是实测还是解析替代；草稿行。

## 实验 9（E1 改版）：无标签 test–retest 信度（GPU，与原实验 3 同量级，夜间串行）

**目的**（审稿 §4 C 表第 8 行 / R3 W13）
原实验 3 用 IC 曲线看 `sample_count` 的效果——那需要标签，而且 IC 的 SE 大到几乎分辨不出东西。
改成 **test–retest 信度**：同折、同模型、同 `sample_count`，**独立打两次分**，
算两次分数的逐日秩相关 `r(sc)`。这是**无标签**量，SE 小几个量级，直接给出
「信号方差 / 采样噪声方差」的分解。**IC 曲线降为辅。**

**判据 / 用途限制（先写死）**
- 诊断 + 估计交付。**不据此改封存口径**（封存队列 sc=5 已完成，不追溯）；
  **不选 sc**——sc=20 已由 `CLAUDE.md` §二「零参数且理论单调」例外条款裁定，本实验不重开该决定。
- 预期方向：`r(sc)` 随 sc 单调不降。**若观察到非单调，只报，不解释成信号性质**
  （更可能是打分批次效应）。
- IC 曲线只报、**不作任何结论**。
- **不得**把两次打分的均值当成一次「sc 翻倍」的打分去和别的 sc 档比 IC（会与 sc 档混淆）。

**步骤**
1. **口径冻结**：`amp=bf16, batch_size=128, lookback=90, predict=6`，
   FT 模型目录 `outputs/fold{f}_lb90_s0_poolB_universe`（f=36..42），**只改 sample_count**。
   开发折正常模式，**不加 `--sealed`**。
2. **种子**：`scripts/evaluate_fold.py` 与 `src/kronos_ft/infer.py` **当前都不设随机种子**
   （全仓 `manual_seed` 只出现在 `src/kronos_ft/train.py:80-93` 与 `src/kronos_ft/rank_head.py:89-90`），
   所以**同配置重跑天然就是两次独立采样，无需改代码即可做 test–retest**。
   若为可复现要加 `--seed`，只能加**默认 None、不传时行为逐位不变**的参数（§0 铁律 5），
   且**先与现有产物对拍**再用。
3. **运行矩阵**（串行，GPU 绝不并发）：`sc ∈ {5,10,20,40}` × `折 ∈ {36,39,42}` × **两次重复**
   = 24 次打分，tag `e9_sc{sc}_r{1|2}`。
   - `sc=5` 的第一次可直接复用已有 `eval_amp_lb90_fold{f}`（同口径），只需补第二次；
     **在交回里写明哪几格是复用的**。
   - 单折耗时随 sc 近似线性（sc=5 约 17 分钟 → sc=40 约 136 分钟，以实测为准）。
   - 用带**互斥锁 + 失败重试**的 `.ps1`（骨架照 §0 表里的既有队列脚本；
     输出用 `Start-Process` 重定向，**别用 `*>`**）。
4. 新建 `scripts/exp9_test_retest_reliability.py`：
   - 对每个 `(fold, sc)`：逐日在**同一日、同一名字集**上算两次分数的 Spearman 秩相关 `r_t`；
     报逐折均值、合并均值、NW(5) SE 与 95% CI。
   - **Spearman–Brown 分解**：两次等长打分的相关即单次打分的信度 `r₁ = r(sc)`；
     则 `信号方差 / 采样噪声方差 = r₁ / (1 − r₁)`；
     「把信度提到 0.95 所需的 sc 倍数」`k = 0.95(1−r₁) / (0.05·r₁)`。
   - **内部一致性检查**：用 `sc=5` 的 `r₁` 按 Spearman–Brown 预测 sc=10/20/40 的信度
     `r_k = k·r₁ / (1 + (k−1)·r₁)`，与实测并列。若实测系统性低于预测，
     说明存在**与 sc 无关的固定噪声成分**——报出来，不解释。
   - **功效对比（本实验的论点，必须算出来交回，不要只写形容词）**：
     把 `r_t` 的逐日 SE 与同折 IC 的逐日 SE 并列，报两者比值——这就是
     「比 IC 曲线功效高几个量级」的实测支撑。
   - **辅**：各 `(fold, sc)` 的 top500 与全池逐日 RankIC 均值 + NW(5) t、十分位价差
     （标签用 FT labels），stationary bootstrap 95% CI（块长 10、10000 次、seed 20260904）。
   - 输出 JSON + SVG 曲线（**纯 python 画**，`.venv` 无 matplotlib，**勿安装**）。
5. **既有对照**：2026-08-29 实测「同模型换批量重打两次分数秩相关仅 0.75」是 sc=5 的一个点；
   新读数应与它同量级，**若差很多先查口径再报**。

**交回**：`r(sc)` 表（逐折 + 合并 + CI）；Spearman–Brown 分解与 `k`；SB 预测 vs 实测；
`r` 与 IC 的逐日 SE 比值；辅助 IC 表；GPU 总耗时；哪些格复用了旧产物；草稿行。

## 实验 11：张成控制集扩充（开发折，CPU 约一天）

**目的**（审稿 C8 + C11；§4 C 表第 7 行）
K6b 的 8 因子控制集**没有换手**这一条件变量，而 Medhat–Schmeling (2022, RFS,
*Short-Term Momentum*) 的核心结论正是「随换手上升、短期反转让位于短期动量，
且在最大最流动的股票里最强」——与本信号画像几乎逐条同构。另缺行业中性化、
SUE / 财报日、52 周高点。

**判据 / 用途限制（先写死；`CLAUDE.md` §二：判据必须先于结果）**
- **先把新控制集的完整定义与本段判据抄进 `scripts/exp11_spanning_extended.py` 的 docstring，
  再跑第一行数据。**
- 门槛**照 K6b 原样，不得改**（ledger:191/192）：量级门槛 **保留率 ≥ 75%**；
  一致性门槛 **逐折（固定载荷残差）alpha > 0 ≥ 5/7**。**两个门槛同时满足**才写「非翻版」。
- 估计交付 + 机械判读：报保留率与逐折。**不得**因为加了控制而回头调 K6b 的门槛。
- 措辞必须带 K6b 已有的限定：保留率 >100% 时附「**正向暴露于本样本内亏钱的因子**」，
  且不得写成 "survives spanning" 式的无限定断言（C11）。

## 实验 12：cost(AUM) 曲线（CPU，约 1 小时）

**目的**（审稿 C2 / C10；§4 C 表第 9 行）
仓库已有容量读数（`HANDOFF.md` §10.4：**\$1M 下冲击 ≤1.3bp、\$30–50M 才咬人**）
与 K13 的名义额 / ADV 分位表（`HANDOFF.md` §11.3），但计划书里没有把它们连成一条曲线。
审稿要的是把「**C 是 AUM 特定的**」画出来，并叠上 BE 与部署判据线。

**判据 / 用途限制（先写死）**
- **估计交付，不作判定**。**不得据此选 AUM**——AUM 是阻塞字段，只能由真实目标部署规模决定
  （`HANDOFF.md` §11.4 第 2 条）。
- 冲击模型的参数必须**文献固定**，**不得在本项目数据上拟合任何一个参数**（拟合 = 开发折搜索）。
  每个参数逐个写出处。
- 曲线是**模型外推，不是测量**；图与表都要标「**模型值，非实测**」。
- 必须写进交回的一句：小试测出的 C 是**参与率≈0 极限下的摩擦**，与本曲线的冲击段不是同一个量——
  `fill − DlyOpen` 在原理上**看不见自身对开盘印价的冲击**（MOO 单共同决定那个印价，
  `HANDOFF.md` §11.4 第 2/3 条）。
- 只用已落盘的 K13 读数与开发折的价量分布，**不新读任何折**。

**步骤**
1. 新建 `scripts/exp12_cost_aum_curve.py`。
2. **冲击模型（写死，文献固定）**：平方根律
   `impact_bp = 10⁴ × Y × σ_d × sqrt(q / ADV)`
   - `Y = 1.0`：Grinold & Kahn, *Active Portfolio Management* (2nd ed., 1999) 与
     Torre / BARRA MarketImpact 的常用中心值；
   - 敏感性 `Y ∈ {0.5, 1.0, 2.0}` 三条线（**只做这三档，不扫**）；
   - `σ_d` = 被交易名字的日收益波动，取开发折 36–42 被交易名字的**横截面中位数**（报出该值）；
   - **对照曲线**：Almgren–Thum–Hauptmann–Li (2005) 的临时冲击形式（**指数 0.6** 而非 0.5），
     参数照原文，用来显示曲线形状对指数的敏感性。
   - 参与率 `q/ADV` 直接取 K13 的名义额 / ADV20 分位表（`HANDOFF.md` §11.3；
     该表列的是**占 ADV20 的 bp**，换算时注意单位）。
3. **AUM 网格** `{1, 3, 10, 30}` M（K13 已有的四档），每档报 p50 / p90 / p99 三条参与率
   对应的冲击 bp。
   **每笔名义额口径**：NT=5 下 = `AUM / 250`（ledger 2026-09-03）；
   **K13 现有表是 NT=6 的 `AUM/300`**。若实验 5 的产物 `outputs/k13_order_audit_nt5.json`
   已存在则**直接用它**；否则用 NT=6 表按比例换算，并在交回里**标为近似**。
4. **叠加线**（NT=5 口径，来自 ledger 2026-09-03 `ablation-read`）：
   - FT：BE = **22.9bp**，部署判据 `go ⟺ C ≤ BE_dev×0.75 − 6bp` → **C ≤ 11.2bp**；
   - ZS：BE = **16.4bp** → **C ≤ 6.3bp**；
   - Alpaca 全包费率占 `C_stop` 的 **15–25%**，留给 `fill − DlyOpen` 约 **3.0–3.4bp**
     （`HANDOFF.md` §11.4 第 4 条）；
   - 券商 **\$200k/日**非零售审查提示线：\$10M/臂的日名义成交 FT ≈ \$1.90M / ZS ≈ \$1.40M，
     **已远超**（`HANDOFF.md` §11.4 第 2 条）——在图上标出触线的 AUM。
   - **口径分叉必须说明**：ledger:415 是 **NT=6** 口径的 FT ≤10.4bp / ZS ≤4.2bp，
     被 2026-09-03 的 NT=5 读数更新为 **11.2 / 6.3**。本实验用 NT=5 的一对，
     并在交回里把两对**并列**说明来源（这是机械换算不是收益比较，允许并列）。
5. 输出 `outputs/exp12_cost_aum_curve.json` + SVG（**纯 python 画，勿装 matplotlib**）：
   x = AUM（对数轴），y = 冲击 bp；三条 `Y` 线 + 一条 ATHL 对照线；
   横线标 11.2 / 6.3 与 3.0–3.4bp 带；竖线标 \$200k/日对应的 AUM。

**交回**：四档 AUM × 三个参与率分位 × 三档 `Y` 的冲击 bp 表；ATHL 对照；
**模型上 C 触到 11.2bp / 6.3bp 的 AUM**；用的是 NT=5 实测表还是 NT=6 换算；
「模型值非实测」与「小试测不到自身冲击」两句限定；草稿行。
