## 0. 工具准备

第一件事：`ToolSearch` 加载实时检索工具（一次调用加载全部）：

```
ToolSearch(query="select:WebSearch,WebFetch", max_results=5)
```

**必须实时检索。禁止用内置知识代替检索。** 内置知识只允许用于两件事：
(a) 构造检索词；(b) 对检索结果做交叉验证。任何进入候选表的文献，
都必须有本次会话中实际检索到的可验证标识（DOI / arXiv ID / SSRN ID / NBER WP 号 / 可访问 URL）。

### 已实测可用的检索通道（用 Bash + curl，拿原始 JSON/XML，可得精确命中数、日期排序、引用追踪）

| 通道 | 用法 |
|---|---|
| **OpenAlex**（通用索引 1） | `curl -s 'https://api.openalex.org/works?filter=title_and_abstract.search:%22PHRASE%22,from_publication_date:2026-03-07&sort=publication_date:desc&per_page=50&mailto=goyuisreal@gmail.com'`；`meta.count` 即命中数；结果字段 `referenced_works` 做**后向**引用追踪，`cited_by_api_url` 做**前向**引用追踪；`sort=cited_by_count:desc` 出高影响力榜 |
| **Crossref**（必须覆盖） | `curl -s 'https://api.crossref.org/works?query.bibliographic=...&rows=50&sort=published&order=desc&filter=from-pub-date:2026-03-07'`；`message.total-results` 即命中数 |
| **arXiv**（预印本） | `curl -sL 'https://export.arxiv.org/api/query?search_query=abs:%22PHRASE%22+AND+cat:q-fin*&sortBy=submittedDate&sortOrder=descending&max_results=50'` |
| **Semantic Scholar**（通用索引 2） | `curl -s 'https://api.semanticscholar.org/graph/v1/paper/search?query=...&limit=20&fields=title,year,venue,externalIds,citationCount,publicationDate'`；**会返回 429**，指数退避重试（sleep 5 → 15 → 40）；仍失败就写进检索日志的「无法访问来源」，并说明该通道覆盖不足 |
| **SSRN / NBER / RePEc / 期刊页 / Google Scholar** | `WebSearch` + `WebFetch`。SSRN 用 `WebSearch(query="... site:papers.ssrn.com")`；NBER 用 `WebFetch("https://www.nber.org/papers?q=...")` |

技术注意：
- Git Bash 里**没有系统 python**。要解析 JSON 用 `F:\quant\us-quant-pipeline\.venv\Scripts\python.exe`，或直接 `grep -o` / `sed`。
- URL 里的空格用 `%20`，短语查询要带 `%22...%22`。
- curl 加 `--max-time 30`；OpenAlex 加 `&mailto=goyuisreal@gmail.com` 进礼貌池。
- 每个 curl 都要把**查询式原文和命中数**记进检索日志。

## 1. 检索纪律（用户硬性要求，逐条满足且必须在输出中留痕）

1. **先构造检索矩阵**，写进输出 §0。矩阵至少包含：
   - 规范术语、同义词、缩写、**旧名与新名**；
   - 方法名、模型名、数据集名；
   - 关键作者、实验室/机构、期刊与会议；
   - 中英文及跨学科术语变体（例如同一概念在 operations research / statistics / ML 里的叫法）。
2. **覆盖面下限**：
   - ≥1 个专业学术数据库（金融口径：SSRN / RePEc-EconPapers / ScienceDirect / Wiley Online Library / Oxford Academic）；
   - ≥2 个通用学术索引（OpenAlex / Semantic Scholar / Google Scholar）；
   - Crossref；
   - 预印本（arXiv q-fin、SSRN）、会议（AFA / WFA / EFA / NBER Working Papers / NFA）、
     核心期刊目录（JF, JFE, RFS, JFQA, Journal of Financial Markets, Review of Asset Pricing Studies,
     Management Science, Journal of Banking & Finance, Financial Analysts Journal,
     Journal of Portfolio Management, Journal of Financial Data Science, Quantitative Finance,
     Journal of Empirical Finance, Journal of Trading, Journal of Investment Management）。
3. **每个查询式至少跑三种**并分别记录命中数：
   - (a) 全时段 + 相关性排序；
   - (b) 近两年（2024-09-03 起）+ 相关性排序；
   - (c) 近 180 天（2026-03-07 起）+ **日期倒序**。
4. **引用追踪**：从种子论文做**前向 + 后向**追踪；新发现的重要论文继续作为新种子迭代，
   直到**至少一轮完整追踪不再产生新的纳入论文**（这一事实要写进 §6 审计）。
5. **候选文献表定稿之前，不得开始写任何结论。** §4 综述必须在 §2 之后写。
6. **候选表列（缺一不可）**：
   `标题 | 作者 | 首次公开日期(预印本/WP) | 正式出版日期 | DOI | 预印本↔期刊版本关系 | 来源 | 相关性 | 方法质量理由 | 重要性理由`
   - 「预印本↔期刊版本关系」要写清：同一篇的 SSRN/NBER/arXiv 版与期刊版是否已确认为同一研究，
     标题是否改过，年份差多少。不能确认就写「未确认」。
7. **四张榜分别输出**：① 最相关；② 最新；③ 高影响力；④ **最新且可能具有高影响力**。
   - ④ **不得只按引用数判断**——要给出非引用数的理由（数据集新颖性、样本覆盖、
     方法可复制性、是否直接检验了净成本后的结果、作者过往命中率、期刊接受状态等）。
8. **完整检索日志**（§1）：数据库、查询式原文、执行日期、命中数、翻页范围、
   排除理由、**无法访问的来源**（付费墙 / 429 / 机器人拦截，逐条列出）。
9. **遗漏审计**（§6）：
   - 给定「候选哨兵论文」的召回情况必须逐条列出（命中 / 未命中 / **无法确认存在**）；
   - 核查近 180 天的核心会议、期刊、预印本；
   - 声明「最后一轮完整引用追踪是否产生新纳入」。
10. **覆盖不足要明说**。若某数据库无法访问或某子问题文献稀少，明确写出限制，
    **不得声称检索已经完整**。
11. **量化领域的时效性纪律**：老而高被引的信号/方法不一定适用现代市场。
    - 不要放过 2020 年后的优质论文；
    - 不要仅凭引用数抬高老论文；
    - 每条纳入文献都要标注 **样本区间、市场、频率、是否含交易成本、是否样本外**。
    - 必须区分「有净成本后实证检验」与「仅理论 / 仅毛收益」的文献。
12. ⚠ **禁止编造（IRON RULE）**。灰区 = FAIL。
    - 拼接 2–3 篇真实论文的元素造出一条不存在的引用，是最严重的失败模式；
    - 任何无法独立确认存在的条目一律剔除，并在 §6 记为「无法确认」；
    - 下面给的「候选哨兵论文」**是未经核实的记忆线索**，必须实时检索确认；
      确认不了就记为「无法确认」，**禁止照抄进正文**。
13. **客观性（用户硬性要求）**：**不要有自己的主观判断，只陈述客观的现象 / 缺失 / 不足。**
    - 允许写：文献报告了什么结果、样本是什么、证据强度如何、哪些地方互相矛盾、
      哪些问题没人做过、方法有什么局限；
    - 禁止写：推荐、建议、「应该这样做」、「对本项目意味着…」、打分式结论、
      「我认为」。对用户给的「待证伪假设」，只陈述**文献是否提供了支持/反驳/无证据**，
      不下最终裁决。

## 3. 输出规格

把**完整结果**写成一个 markdown 文件到指定路径（UTF-8，中文为主，学术术语保留英文）。
结构固定为：

```
# <主题名>
## §0 检索矩阵
## §1 检索日志（表格：数据库 | 查询式 | 日期 | 命中数 | 翻页 | 排除理由）
### §1.x 无法访问的来源
## §2 候选文献表（十列全）
## §3 四张榜
### §3.1 最相关  ### §3.2 最新  ### §3.3 高影响力  ### §3.4 最新且可能高影响力
## §4 主题综述（按分派给你的子问题分节；逐条对应「待证伪假设」，只陈述证据/缺失/矛盾）
## §5 覆盖缺口、方法不足与限制
## §6 遗漏审计（哨兵召回逐条 + 近180天核查 + 引用追踪终止条件）
```

**规模要求**：纳入文献不少于 25 条（若确实找不到，在 §5 说明并给出已穷尽的检索证据）。
§4 综述 2000–4000 字。

写完文件后，**在对话里只返回 ≤400 字的要点摘要 + 文件绝对路径 + 纳入文献数 + 无法确认的哨兵条数**。
不要把全文贴回对话。
