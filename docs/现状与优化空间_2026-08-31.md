## 1. 任务与数据的精确定义

### 1.1 数据

| 项 | 内容 |
|---|---|
| 主数据 | CRSP CIZ 日线全量 **2000-01 .. 2025-12**，4987 万行，含退市、point-in-time |
| 字段 | `DlyOpen / DlyHigh / DlyLow / DlyClose / DlyVol / DlyPrcVol / DlyRet / DlyFacPrc / DlyCap` |
| 复权 | 事件 = `distype='FRS'`，factor = `1 + disfacshr`；`DlyFacPrc` = 当期事件因子 |
| 外部因子 | JKP 全球因子面板（13 主题日频 + 市场），仅用于归因，**CC BY-NC 禁商用** |
| **没有** | 分钟级数据、bid/ask、另类数据、Compustat（可接但未接） |
| 算力 | 单张 RTX 4080 Super 16GB；整机 31GB 内存，提交上限 55.9GB 常年吃紧 |

### 1.2 折设计（滚动前进，42 折）

```
fold01: 训练 2000-01-03..2002-12-20 (3年) | 验证 2003-01-02..2003-06-30 (6个月)
fold02: 整体前滚 6 个月
...
fold42: 验证 2023-07-03..2023-12-29
封存窗: 2024-01-01 起全部未看；主判读窗 2024-07..2025-12
        （Kronos 预训练数据截至 2024-06 且含美股，2024H1 被基座见过）
```

**折的消耗状态（关键）**：
- **折 01–04**（2003–04）：被早期 lookback 粗筛消耗，读数为方向性证据
- **折 05–35**（31 折，15.5 年，2005–2020，含 2008 与 2020Q1 两次崩盘）：**完全未碰**
- **折 36–42**（7 折，832 日，2020H2–2023H2）：**三天内被用于数十次决策读数**
  （lookback 选档、universe 收窄、持有期、执行时点、合成取舍、正则强度、
  微观结构检验、中性化检验……），已不是无偏估计。
  选择偏差自估 +0.002~0.003（10–15%），对抗性复核认为应为 +0.004~0.006（20–28%）
- **封存窗 2024-07 起**：一眼未看

### 1.3 Target function（三层，容易混淆，务必分清）

**(a) 训练目标** = Kronos 原生**生成式**目标，**不是**监督横截面排序：
- tokenizer 阶段：`mse(z, x)`（量化重建）
- predictor 阶段：OHLCV token 分布的 NLL（自回归下一 token）
- 输入只有单只股票自己的 OHLCV 序列，**看不到市场指数、同行、截面位置**

**(b) 打分（readout）** = 手工写死、**在本项目数据上零自由参数**：
```
score(t) = predOpen(t+6) / predOpen(t+1) − 1
```
其中 pred 来自 Kronos 对 t+1..t+6 的生成式预测。
采样参数 = 官方 backtest 配置：`T=0.6, top_p=0.9, top_k=0, sample_count=5`
（多路径在 `predict_batch` 内部取均值）。lookback = 90 个交易日。

**(c) 评估标签** = execution-return，6 交易日，**可实现口径**：
```
t+1 open 建仓（entry_open = 实际 DlyOpen）
首日段:  t+1 close / t+1 open − 1
中段:    t+2 … t+5 逐日复合 DlyRet
退出段:  t+6（含 ex-date 股息处理；退市按 Shumway 档位处理，业绩类退市才插补）
label = gross − 1
```
`status` 区分 ok / unfillable（停牌 vs 退市）/ invalid。

**(d) 主评估指标** = 逐日 Spearman **RankIC**（score vs label），Newey-West t。
注意 RankIC 已在项目内部**降级为诊断**，主指标是冻结构造下的净夏普。

### 1.4 变现构造（已冻结）

| 参数 | 值 | 怎么定的 |
|---|---|---|
| universe | 流动性前 500（ADV20，point-in-time） | 在折 36–42 上选 |
| 档位 | 六档错位 NT=6，每天重平衡 1/6 | 持有期扫描，在折 36–42 上选 |
| 进入 | 分数前 10% | 预注册 |
| 退出 | 跌出前 30% 才卖（省着换） | 在折 36–42 上选 |
| 建仓 | t+1 开盘 | 预注册（执行时点检验通过） |
| 成本 | 8bp 单边（top500 档） | 外生假设，**未实测** |
| 基准 | 同池等权 | 预注册 |

**⚠ 上表里「在折 36–42 上选」的四项，是后续所有偏差讨论的来源。**

|---|---|---|

## 3. 三个核心难点

### 难点一：钱的链条在**跨年代**上断了（当前最大的负面证据）

同一冻结构造套到折 01–04（2003–04）：

| | 全池 IC | **top500 IC** | σ_cs | 上十分位−均值 | **毛纯多超额** | breakeven |
|---|---|---|---|---|---|---|
| 2003–04 | +0.0178 | **+0.0116**（掉 35%） | 4.38% | 9.2bp | **+0.83%/年** | **3.4bp** |
| 2020H2–23 | +0.0207 | **+0.0258**（涨 25%） | 5.47% | 36.0bp | **+10.48%/年** | 21.9bp |

**成本为零时 2003–04 也几乎不赚钱**，所以这不是「拿 2024 年成本回测 2003 年」。
（这条曾被一个对抗性审阅者按桥公式外推预测为「毛约 +9%、需 28bp 成本才解释」，
实测证伪，差一个量级。）

十分位曲线（相对池均值，bp，最低分档在左）：
```
2003–04    +3.5  +1.0  −6.3  +1.1  −6.7  −3.3  −1.6  +3.0  +0.2  +9.2   ← 非单调，两端皆正
2020H2–23 −29.7 −15.0  −7.5  −3.5  −5.7  +3.8  +2.3  +3.9 +15.4 +36.0   ← 单调
```
2003–04 两端皆正、中间塌陷 = 分数在抓波动/离散度而非方向，与「2003 垃圾股狂奔、
低价高 beta 领涨」相符。

**已排除的一个解释（K6c，判据先于结果写死）**：曾假设 A.1 的机制是「策略的因子
倾斜在近代顺风、在 2003–04 逆风」。把 §3.2 的 8 个控制因子与整套张成回归原样套到
折 01–04（**两个年代的策略腿与控制腿一律用毛收益**，移除成本模型混淆项）：

| | 策略毛超额 | **S1b alpha** | t | 逐折 alpha>0 |
|---|---|---|---|---|
| 2003–04 | +0.83% | **+0.46%** | 0.15 | 2/4 |
| 2020H2–23 | +10.48% | **+13.33%** | 3.03 | 6/7 |

四个正载荷因子**确实 4/4 随年代翻转符号**（2003–04 全为正收益、近代全为负），
但方向与假说**相反**：2003–04 的因子暴露是**顺风**，控制掉后 alpha 从 +0.83%
降到 +0.46%；近代是逆风，控制掉后从 +10.48% 升到 +13.33%。

**所以因子倾斜不仅不能解释 A.1，反而使其更严重：控制掉整个短周期价量因子族之后，
2003–04 的纯信号 alpha 仍约为零（+0.46%, t=0.15），近代为 +13.33%(t=3.03)，
相差约 29 倍。**

**两个仍未区分的解释**：
(a) 基座只适配现代微结构、早期年代不适用 → 折 05–35 大概率也失败（**K6c 后后验上升**）；
(b) 2003–04 是全样本最糟的一次训练-验证机制错配（训 2000–02 互联网崩盘 /
验 2003–04 暴力反弹 + 垃圾股行情）→ 属单一异常，折 05–35 未必失败。
仅 4 折，无法排除。

### 难点二：alpha 依赖于「所暴露因子在本样本内亏钱」

K6b 张成检验（控制集 = 1日/5日反转 + 短期动量 skip-1w + 12-1 动量 + Amihud +
成交量冲击 + 特质波动 + 相对价差代理，全部走与策略逐行相同的管道、多空价差腿、
毛收益；判据先于结果写死）：

- **S1b alpha +9.85%，保留 141%，t=2.24，逐折 6/7** → 判「非翻版」
- 策略站在**短期动量**侧（mom_skip β=+0.07, t=+3.6；rev1 β=−0.12, t=−2.2），
  不是短期反转/流动性提供侧。与文献一致：短期动量在大盘 0.62%/月且显著，
  且随换手上升反转让位于动量——本项目 universe 正是流动性前 500。
- **⚠ 但保留率 >100% 的机制是**：策略正向暴露于在本样本内**亏钱**的因子：

| 因子 | 2020H2–23 毛年化 | 与策略相关 |
|---|---|---|
| mom_skip | **−6.28%** | +0.211 |
| amihud | **−11.20%** | +0.326 |
| idiovol | **−10.70%** | +0.317 |
| hlrange（价差代理） | **−11.45%** | +0.291 |
| invprice | −0.26% | **+0.382** |

**换一个这些因子赚钱的年代，同样的正载荷就变成净拖累。**
2003–04 正是这样一个年代（四个因子 4/4 转正）——但 K6c 已证明**这不能解释难点一**，
见 §3.1。也就是说：因子暴露的年代翻转是真的，但它之外还有一个更大的、未解释的
年代效应。

**衍生问题（成本）**：策略在 top500 池内系统性偏向低价/不流动/高波动一端，
所以**全池统一 8bp 低估了真实成本**——持仓落在该池最贵的尾部。

### 难点三：样本长度 + 已消耗折 + 预训练污染，三者叠加

- 夏普 0.72 × √3.3年 = 1.30 ≈ 实测 t=1.32。**「策略是否显著」用七折在原理上无解。**
  要 t>2 需约 8 年，t>2.8 需约 15.5 年（= 折 05–35 的长度，「刚够」）。
- 折 36–42 已消耗数十次读数；折 05–35 是唯一一次性的统计资本。
- **预训练污染**：Kronos 语料 = 45 个交易所、120 亿根 K 线、截至 2024-06 且含美股，
  **折 01–42 全部落在语料窗口内**。2025–26 已有针对性文献
  （TSFMAudit arXiv 2605.26161；arXiv 2510.13654，记录 0.1% 重叠即可使误差被
  低估 8–29pp），推荐标准是「严格的全局 post-training 测试期」。
  **含义：折 05–35 的通过是弱证据、不通过是强证据；唯一双重干净的是封存窗 2024-07 起。**

## 4. 已经排除的方案（请不要重复建议）

### 4.1 模型层
- **继续加微调轮数 / 搜学习率**：e1 ≈ e30（判「不可分」）；微调整体贡献 <8% 且 4/7 折
- **冻结主干 + 学习读出**：线性探针 +0.0126（513 参数）、MLP 头 +0.0075（66k）——
  都明显劣于零样本 +0.0192。瓶颈是估计方差不是探针容量
- **标签变换**：转秩 +0.0195 > 原始收益 +0.0160 > z-score +0.0064 > 去均值 +0.0013
  ——现用的转秩恰是最好的，不是问题所在
- **多档 lookback 合成**：七折仅 +3.1%，不值双倍成本
- **拉长持仓期**：解析最优 T*=3~5（bootstrap 中 T=6 占 4%），但 T=4 vs T=6 不显著
  （P=0.84）；21 日持仓转负
- **夜盘/盘前执行**：信号半衰期约 2 日，越早成交越吃亏（延迟建仓 1 日保留 85%、
  2 日保留 62%、3 日 35%）

### 4.2 变现层
- **多空**：空头腿七折 RankIC 均不显著；且 top500 全 ETB 的 universe 恰是
  Muravyev-Pearson-Pollet (JF 2025) 证明「短端 alpha 住在贵借券股票里」的子样本
  ——空头腿不显著是对该论文的成功复现，调参救不了
- **给纯多加杠杆**：有效借款利率 6.25% ≈ 每单位 gross 超额，起点即盈亏平衡
- **提高传导率**：实测传导率（隐含年毛 → 实际净超额）≈ **0.46**，corr=0.92；
  Clarke–de Silva–Thorley 的 transfer coefficient 实务区间就是 0.3–0.8，
  **0.46 是长纯多约束的正常标价，不是可修的低效**

### 4.3 统计层
- **η（IC → 毛十分位价差的乘子）不稳** —— 已证伪：无截距回归 η = **0.902，
  95% CI [0.813, 0.960]**（832 天 stationary bootstrap）。桥公式
  `毛十分位价差 ≈ 3.51 × IC × σ_cs` 成立且稳定
- **手数试验数做 Bonferroni** —— 已改用 Hansen SPA_c，p=0.0008；
  但**只覆盖 4 个配置**（lb90/lb200/零样本/e001，881 个共同交易日），
  universe/持有期/执行时点/合成/正则那些试验没有逐日 IC 产物，**覆盖不足**

### 4.4 已知会失败的
- 从零训练截面 Transformer / GNN / learning-to-rank：见 §2.1 的自由度关系，
  且确认集只有一个、试验预算已透支
- Bai-Perron 未知断点搜索：t≈3 的功效检不出子样本断点
- Corwin-Schultz 价差估计：大市值相关性仅 18%

## 5. 还没试过的选项

1. **截面上下文探针扩到七折**。现为五折 +11.6%（+0.01909 → +0.02130）、3/5 折，
   按预注册判据（均值 ≥+0.003 且 ≥4/5 折）判「边际」——**功效不足，不是结论**。
   设计 = 保留手工读出（零自由参数）+ 8 个截面上下文特征 + 岭回归跨折滚动。
2. **Chronos-2 的 group attention**：唯一「真看截面 + 零新参数」的路径
   （一组股票原生一起前向）。但非金融原生预训练，正确用法可能是作为与 Kronos
   正交的第二信号**等权**合成（等权 = 零自由度），而非替换。
3. **WiSE-FT 权重插值**：θ(0.5) = 零样本与微调权重的逐元素平均。两组权重都在手上、
   微调仅 4/7 折更好，是教科书适用场景。零新参数，半天可验。
4. **sample_count 继续加大**：5→20 实测五读数平均 **+4.9%，4/5 为正**
   （低于论文 Fig.7 的 +9.7% 与 Spearman-Brown 外推的 +10.8%）。40/80 未试。
5. **EDGE 有效价差估计器**（Ardia-Guidotti-Kroencke 2024）：闭式、只需 OHLC，
   给 2000–2025 逐股逐月有效价差 → 同时解决成本模型的「年代适配」与「截面适配」。
6. **事前因子中性化**：构造时约束对 amihud/idiovol/hlrange 的暴露 |β|≤0.1，
   而非事后回归。若中性化后收益塌掉，说明收益本来就来自那些暴露。
7. **容量分析**：按持仓实际 ADV 与参与率算 8bp 在多大 AUM 上成立。**至今未算。**
8. **多信号合成**：IR_comb = IR×√(k/(1+(k−1)ρ))；3 个 ρ≈0.2 的信号把 0.72→1.05，
   证明时间从 7.7 年压到 3.6 年。但另外两个信号目前**不存在**。

## 6. 待决的主要决定

**确认集（折 05–35，15.5 年）到底跑不跑、主终点是什么。**

内部建议（未拍板）：
- **主终点改为十分位曲线的单调性**（Patton-Timmermann MR 检验）。理由：
  2003–04 真正坏掉的就是它；估计量来自约 500 名字 × 约 3900 天，功效远高于折级收益；
  **对成本模型完全不敏感**（毛的量），因而失败可归因——而固定 8bp 的净超额在
  2005–2020 是已知错误的模型（2003 年机构全成本按 GAO/Plexus 约 50bp/单边），
  失败无法归因
- 次终点 = 年代适配成本下的净超额；RankIC 降为诊断
- 预注册其解释力上限（预训练污染 → 通过是弱证据、不通过是强证据）
- 候选配置 ≤3（Bonferroni t 门槛 2.39）

## 附：本项目的方法学纪律（背景，便于理解为什么很多事不能做）

三天内由 AI 助手引入并自行发现的方法学错误四类，**无一例外都朝「结果更好看」
的方向错**：前视（把未来收益的截面标准差当特征，贡献 37% 表观增益）；
在评估窗上选超参（实测偏差 +0.0070，比信号本身的三分之一还大，且**修完当天重犯**）；
判据只有量级门槛没有一致性门槛（2/7 折为正时仍判「有价值」）；执行时点早一天。

由此形成的强制规则：判据必须先于结果写死；判据必须同时含「量级」与「折数同向」；
任何超参必须在与评估窗分离的数据上选；登记簿 append-only；
**评估折是消耗品**。本文所有读数都受此纪律约束——这也是为什么「在开发折上再试
几个变体」不是一个可接受的建议。

本会话另有两次「把噪声读成结构」并已撤回（η 的比值假象、一致性门槛误用逐折
独立回归），共同机制是**在 n=7 上做推断而手上有 832 天**。现已强制新结论先做
block bootstrap。
