## 0. 结论先行

### 0.1 H_E 判定：前半句被证伪，后半句没被证伪也没被证实，但证据方向对本项目不利

H_E =「①成本、延迟、覆盖三方面个人都做不到；②即使做到，新闻情绪在大盘股、一周期限上没有独立于价格的可靠预测力」。

- **①被干净地证伪。** 数据你已经有了（Alpaca 账户自带 Benzinga 新闻 API，免费、历史回到 2015）；全美股每天只有 **600–900 条**公司新闻【官方】，不是几十万条；打分用本地 149M 参数模型在你这张卡上是秒级；用 API 大模型约 **0.03 美元/天**。延迟对你根本不是约束——t 收盘算分、t+1 开盘成交，中间有一整夜。
- **②未证伪，但我核到的每一条证据都指向同一个方向**：效应集中在**小盘**、集中在**一到两天**，在大盘上迅速消散。**没有任何一篇论文直接报过「大盘 × 一周持有」的量级——这个数未核**，而且我怀疑它没被单独报过。
- **一条你没问、但更致命的**：Lopez-Lira & Tang 的成本敏感性是 5bp 累计收益 >300%、10bp >100%、**20bp 策略不赚钱**【文献，已读全文】。你的 breakeven 是 22bp。**这条新闻策略的成本悬崖正好落在你所在的位置。**

### 0.2 「要分析的股票太多」——三句直接回答

1. **不要按股票打分，按新闻条目打分。** 全美股每天 600–900 条公司新闻，落进你 top500 的更少；当天没新闻的股票就是缺失值，根本不需要算。工作量从「500 只 × 每天」变成「几十到几百条 × 每天」。
2. **工业界做的就是这件事**：RavenPack / Bloomberg / LSEG 是逐篇文章做「实体识别 → 相关度打分 → 事件与情绪打分」。他们贵是因为要覆盖全球四万个源、几十万个实体；你只要一个源、500 个实体，这部分成本对你趋近于零。
3. **真正的瓶颈不是算力，是两件别的事**：信号活不到第 6 天（§2、§6）；以及历史回测拿不到干净的模型（§6）。

### 0.3 推荐的最小可行方案

**不要先建信号，先花 1 人日建一个「覆盖统计」。** 用 Alpaca 免费历史新闻（2015 起）算清楚：你的 top500 里，每天有新闻的股票有多少只、分布怎么样。这个数决定信号的**广度**（每天能排序多少只），广度不够时后面一切都不用谈。零 GPU、零成本，且符合项目「先算 MDE 再做实验」的纪律。

若通过再走第二步：**用 ChronoBERT 零样本，不要用 FinBERT，也不要用今天的 GPT/Claude 去打历史标题**（理由见 §6）。

## 1. 规模问题的工业解法

【厂商口径，已核】RavenPack 的做法是**逐篇文章**：**相关度（Relevance）0–100**——0 表示该公司只是被顺带提到、100 表示它在标题的首个事件里扮演关键角色；分数由「实体在事件中扮演什么角色 + 出现在第几段」的算法给出，不是关键词计数。**事件情绪分（ESS）** 是 −1 到 1 的实体级分数。这正是「逐篇预算」的标准形态：一篇文章可能产生多条 (公司, 相关度, 情绪) 记录。

**价格量级**：Bloomberg 终端 **$31,980 / 座 / 年**（2026，第三方报价站，**非官方页**）；LSEG Workspace 约 **$22,000 / 年**（同源）。RavenPack 官网不公布价格，某学术论坛提到 **2 万–4 万 / 年**（币种与档位不明）。**这三个数都是「有出处但非官方」，采信前须自行询价。** 结论不变：**个人买不起，也不需要买。**

**个人档（都提供逐篇 ticker 标注）**【厂商页 / 第三方评测页，非同行评议】：Benzinga（经 Alpaca 免费给你，2010 起，实时，**不自带情绪分**）；Tiingo（2014 起，**不自带情绪**，$0–30/月）；Polygon（现更名 Massive；2016 起付费，AI 生成的分类情绪标签，$0–29/月）；Finnhub（仅美股，`companyNewsScore` **算法未公开**）；EODHD（词典极性 + 日聚合 −1..1，€19.99 起，全家桶 €99.99/月）；Marketaux / StockNewsAPI / Alpha Vantage（$0–50/月档）。

**判断**【推断】：自带情绪分的这几家，算法要么不公开、要么是词典法——**「超参可文献固定」这条不成立**，而且你无法审计它的时点（分数是什么时候算的、有没有事后重算）。**你已经有的 Benzinga 原始文本 + 自己打分反而更干净**，这和上一份调研里「直接解析 EDGAR 比用 Thomson Insiders 干净」是同一个道理。

## 2. 学术解法：一周期限上还剩多少

- **Tetlock 2007**（WSJ「Abreast of the Market」专栏的悲观度）：**是市场总量择时，不是截面选股**；高悲观度压低指数、随后一两个交易日回归。把它放进选股清单是类别错误。
- **Tetlock–Saar-Tsechansky–Macskassy 2008**：公司层面，负面词占比预测**次日**收盘收益。预测期 = 1 天。
- **Ke–Kelly–Xiu（SESTM）**：Dow Jones Newswires 机器可读档，1989-01 至 2017-07，**22,471,222 篇**。策略是**每天**买情绪最高的 50 只、卖最低的 50 只，**日换手约 94%**。等权年化 35.56%、SR 2.21（一处检索摘要）；另一处摘要给等权 SR 4.3、**价值加权 SR 1.3**——**两处数字互相矛盾，我没能打开原文表格，一律标未核**。成本设定为 NYSE 规模 80 分位以上 10bp、其余 20bp。另有摘要称「扣成本后周 / 月 / 季等权 SR 分别达 4.0 / 1.5 / 0.9」以及「限制到最流动股票后等权与价值加权 SR 仍超过 1.0」——**这两句最贴近你的问题，也恰恰是我未核到原文的两句。**

  【推断，但算术是硬的】价值加权 ≈ 大盘主导。94% 日换手 × 10bp ≈ **每年 23.7% 的成本**。SR 1.3 的价值加权腿要抗住这个数，毛年化得远超 20%。**日频新闻策略在大盘上大概率是成本死的**——这也解释了为什么它必须靠等权（= 小盘权重大）才好看。

- **Chen–Kelly–Xiu《Expected Returns and Large Language Models》**：用 LLM 嵌入构造新闻信号，扣成本后仍有经济意义的夏普，且在控制**反转**与公司特征后仍有增量信息。**关键一句**：短期新闻动量「在小盘股上可持续数日，在大盘股上迅速消散」——这是我核到的、针对「大盘 + 6 日」最直接的**负面**证据。

## 3. LLM 路线

**Lopez-Lira & Tang 2023**【文献，arXiv HTML 已读全文】：**只用标题，不用全文**。RavenPack + 网抓，2021-10 至 2024-05，**159,137 个 firm-headline-date 观测**、**4,123 家公司（≈ CRSP 宇宙的 85%）**、**约 174 条 / 天**（他们过滤后的口径）。预测期：隔夜反应 + 之后**一到两个交易日**的漂移。GPT-4 隔夜漂移策略年化 **SR 2.97**、日均 34bp、漂移方向命中率 58%（初始反应命中率 93.3%，但那一段不可交易）。

- **分层**：小盘显著更强（规模交互系数 0.404，t = 4.75）；负面新闻远强于正面（SR 2.01 vs 0.78）。
- **成本悬崖**：5bp → 累计 >300%；10bp → >100%；**20bp → 不赚钱**。
- **模型对比（同一评测的漂移 SR）**：GPT-4 2.97 / GPT-3.5 1.66 / DistilBart-MNLI 1.26 / Llama2-70B 0.97 / **FinBERT −0.33** / GPT-2、GPT-1、BERT 更差。

**→ 两条对本项目最重要**：(a) 效应在小盘、在 1–2 天，正好是你宇宙与持有期的反面；(b) **FinBERT 零样本在这份评测里是负的**——「本地 FinBERT 打分」这条最省事的路，证据不支持。

**本地吞吐**【弱证据 + 推断】：检索到的口径是 FinBERT 在 T4 上约 50ms / 篇、批量 32 时 50 条标题在 CPU 上亚 2 秒。**没有 4080 Super 的官方基准（未核）。**【推断】按 batch=64、序列 64 token，本地每秒数百条是保守估计——**每天几百条 = 几秒**。算力从来不是这条路的瓶颈。

## 4. 覆盖的真实分布

- 【官方】Alpaca 文档：平均 **130+ 篇 / 天**（长文）；Alpaca 博客更细：**600–900 条实时标题 / 天 + 130–160 篇带图长文**，历史回到 2015，免费档 200 次 / 分钟。
- 【厂商口径】Benzinga：每天 600–900 条公司新闻、约 1,000 条快讯标题，覆盖 Wilshire 5000 再加 1,000 只美股。
- 【厂商口径】RavenPack Dow Jones 版：约 **16,500 条记录 / 天**（全球、全实体，含非股票）。
- 【文献】Glasserman–Lin 的 Thomson Reuters 子样本：**181,908 条标题 / 678 家 S&P 500 公司 / 2015-01 至 2022-12**。【推断】≈ 90 条 / 天、**每家大盘公司约 0.13 条 / 天**。
- 【文献】Fang & Peress 2009：**90% 以上的小公司完全没有媒体覆盖** → 覆盖高度集中于大盘。**这对你是好消息**：你的宇宙恰是覆盖最密的一侧。
- **「top500 里每天有新闻的股票占比」我没核到任何直接数字（未核）。** 这是本报告最该由你自己在一天内算出来的量，也是 §0.3 建议的全部内容。

## 5. 省算力的标准做法（各自出处）

1. **只打标题不打全文** —— Lopez-Lira & Tang 全程只用标题【文献】；Glasserman–Lin 同样只用标题【文献】。
2. **只对当天有新闻的股票打分** —— 这支文献全是事件级的（新闻 → 分数 → 当日聚合到公司），没有一篇是「对全宇宙每天强制打分」【文献，结构性】。ChronoBERT 论文的聚合窗口写得很明确：「t−1 日 16:00 到 t 日 16:00 之间该公司的全部标题」【文献】。
3. **多条标题拼一个 prompt / 小模型先过滤再大模型精判 / 蒸馏** —— 有证据但等级低：TinyFinBERT 用 GPT-4 增强数据做两级蒸馏；伪标签 + 一个 MLP 能逼近 GPT-4 表现【**均为预印本，弱证据**】。
4. **事件触发而非日频全量** —— 是第 2 条的直接推论【推断】。

## 6. 前视污染：这条路最硬的一堵墙

- 【文献】**Sarkar & Vafa 2024（ICML 2025）**：直接检验证明 LLM 把预训练语料里的未来信息漏进了「预测」（例：在知识截止日之前「预测」公司风险因子时，用上了 COVID 的知识），而且**在 prompt 里叫它「别用未来信息」是无效的**。
- 【文献】**Lopez-Lira, Tang & Zhu 2025《记忆问题：能信任 LLM 的经济预测吗》**：LLM 能背出历史金融数据 → 必须用知识截止日之后的样本。
- 【文献】**Glasserman & Lin 2023**（已读全文）：把标题里的公司名替换成 "Blahblahblah"，并用 Google Knowledge Graph 把该公司的产品名一并替换（成功匿名化 100,401/129,431 与 180,237/181,908 条）。结果反直觉：**样本内匿名化反而更赚**（TR 样本 81.64 vs 77.27 bp/日，p = 0.017），说明**「干扰效应」大于「前视效应」**——LLM 对公司的一般知识干扰了它读这条标题本身的情绪；**而且干扰在大公司上最强**。样本外 S&P 500 上匿名化 12.23 vs 原始 6.07 bp/日（p ≈ 0.064）。
- 【文献】**He–Lv–Manela–Wu《Chronologically Consistent LLMs》**（已读全文）：按年份切语料训练的模型族，1999–2024 共 26 个版本，**ChronoBERT 149M / ChronoGPT 1.5B**，在 HuggingFace `manelalab` 公开。截止日之后的事件预测正确率仅 1/78 与 4/78（几乎零泄漏）。在 DJ Newswire 2008–2023 上，日频等权十分位多空 SR：ChronoBERT 4.80、ChronoGPT 4.92、Llama 3.1 4.90、FinBERT 3.86（**未扣交易成本**）；与 Llama 3.1 之差不显著（p = 0.315 / 0.547），作者据此认为前视偏差影响不大。收益在 **Day 0–1 陡降，Day 3–6 各模型趋同**。

**对本项目的含义（本报告最重要的一段）：**

1. **新闻信号能有干净的历史回测——但只有 ChronoBERT / ChronoGPT 这一条路。** 用今天的 GPT/Claude 去打 2005–2020 的历史标题，回测结论不可信（Sarkar–Vafa + Lopez-Lira–Tang–Zhu）。
2. **但 ChronoBERT 的已知有效用法与本项目纪律直接冲突。** 该论文的收益预测**不是零样本情绪读出**，而是「取嵌入 → 每月做 Fama-MacBeth 截面岭回归 → 用过去系数均值预测」——**这正是「从自己数据学映射」**，本项目已四次实测证伪（线性探针 0.0126 vs 零样本 0.019）。而同一批模型里**真正零样本的那条（FinBERT）在 Lopez-Lira 的漂移检验里是 −0.33**。
   **→ 结论：干净的历史回测要求 ChronoBERT；ChronoBERT 的已知有效用法要求学映射。两者不能同时满足。** 这是新闻信号与「外部预训练模型零样本读出」这一范式之间的**结构性冲突**，不是工程问题，也不是调参能绕开的。
3. **Day 3–6 趋同** = 你的 6 日持有窗口里，**后四天基本没有新闻信息**。
4. 你的宇宙全是大盘股 = Glasserman–Lin 说的「LLM 干扰最严重」的那一侧。

**所以：新闻信号只能前向验证，不能有你认可标准下的干净历史回测。**（除非 §10 第 3 条那个未知数被填上。）

## 7. 与价格信号的相关性

- 【文献】SESTM 多空组合对 Fama-French 因子的日频 R² **最多 10%**（单边长 / 短腿最多 41%），平均收益「几乎全是 alpha」→ 对**标准价格因子**的正交性不错。
- 【弱证据】一篇 EFMA 2020 会议论文称动量因子与部分新闻情绪因子高度相关（「两者从相似来源取信息」）；**量级未核**。
- 【文献】Chen–Kelly–Xiu：LLM 新闻信号在控制**短期反转**与公司特征后仍有增量信息。
- **与 Kronos 的相关性：未核，也不可能有文献。**【推断】机制上应当低（Kronos 只看单只股票的 K 线历史，新闻是外生文本流），但**必须自测**。需要注意的是：新闻效应期 1–2 天，与短期反转高度重叠，而「Kronos 与短期反转的关系」本项目也未测——所以「新闻与 Kronos 低相关」目前**只是猜想**。

## 10. 哪些数字未核（按重要性排序）

1. **top500 里每天有新闻的股票占比** —— 决定广度，也是唯一你一天内能自己算出来的关键量。
2. **SESTM 原文表格四条**：等权 SR 到底是 2.21 还是 4.3；价值加权 1.3 的口径；「周 / 月 / 季扣成本后 SR = 4.0 / 1.5 / 0.9」；「限制到最流动股票后 SR 仍 > 1.0」。**四条全部只有检索摘要，PDF 打不开。** 其中任何一条为真都会显著改变判断——尤其是最后一条，它是唯一可能推翻 §0.1 第二点的证据。
3. **ChronoBERT 的零样本情绪读出**（不做岭回归）有没有预测力 —— 论文只报了「嵌入 + 回归」的版本。这是唯一能同时满足「干净回测」与「不学映射」的组合，而它**没有已知读数**。
4. **大盘子样本 × 5–10 日持有** 的新闻情绪量级 —— 我没找到任何一篇直接报过。
5. RavenPack / LSEG 的真实个人报价；Alpaca News API 在 2026 年是否仍免费（文档说免费，但博客写的是「beta 期免费，之后可能改」）。
6. 4080 Super 上 FinBERT / ChronoBERT 的实测吞吐。
7. 新闻情绪与 **Kronos** 的秩相关 —— 不可能有文献，必须自测。
