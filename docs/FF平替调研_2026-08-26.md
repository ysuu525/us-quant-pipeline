## 二、关键核实要点

### Ken French：CIZ 口径与 RF 变更（对齐时必读）

- 官网 *Changes in CRSP Data* 页明确：CRSP 传统格式 (FIZ) 文件 2024-12
  数据发布后停止供应；**自 2025-01 数据发布起改用 Flat File Format 2.0
  (CIZ) 生成美国研究收益**。FIZ 下月度收益是月末到月末持有期收益、股息月末
  再投资；CIZ 下是**日收益复利、股息除息日再投资**。今天下载到的整条序列都
  是 CIZ 口径——把它当自建 CIZ 面板校验基准的价值正在于此。
- **无风险利率 2024-06 起改用 ICE BofA US 1-Month Treasury Bill Index**
  （之前是 Ibbotson）。做超额收益对比统一取 French 文件里的 `RF` 列，
  避免伪差异。
- 构造口径：universe = NYSE/AMEX/NASDAQ、share code 10/11；FF3/FF5 每年
  6 月按 NYSE 断点重排；Mom 按 (2-12) 期收益**月度**成组、NYSE 30/70 分位。
  官方构造文档：Fama & French, SSRN #4629613（sanity check 前值得通读）。

### 下载解析片段（零第三方依赖，管线内正式路径用这个）

```python
import io, re, zipfile, requests
import pandas as pd

FF_BASE = "https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/"
FF_HEADERS = {"User-Agent": "Mozilla/5.0 (compatible; quant-pipeline/1.3)"}

def fetch_ff_daily(name: str) -> pd.DataFrame:
    """name 例: 'F-F_Research_Data_Factors_daily'。
    返回 DatetimeIndex 索引、小数（非百分数）单位的日频因子表。"""
    r = requests.get(f"{FF_BASE}{name}_CSV.zip", headers=FF_HEADERS, timeout=60)
    r.raise_for_status()
    with zipfile.ZipFile(io.BytesIO(r.content)) as z:
        raw = z.read(z.namelist()[0]).decode("utf-8", errors="replace")

    lines = raw.splitlines()
    is_row = lambda s: re.match(r"^\s*\d{8}\s*,", s) is not None
    first = next(i for i, s in enumerate(lines) if is_row(s))
    cols = ["date"] + [c.strip() for c in lines[first - 1].split(",")[1:]]

    body = []
    for s in lines[first:]:
        if not is_row(s):
            break          # 尾部年频块/版权说明，遇到即停
        body.append(s)

    df = pd.read_csv(io.StringIO("\n".join(body)), header=None, names=cols)
    df["date"] = pd.to_datetime(df["date"].astype("int64").astype(str), format="%Y%m%d")
    num = [c for c in df.columns if c != "date"]
    df[num] = df[num].apply(pd.to_numeric, errors="coerce")
    df[num] = df[num].mask(df[num] <= -99.0)   # -99.99 / -999 是缺失哨兵
    df[num] = df[num] / 100.0                  # 原文件单位是百分数
    return df.set_index("date").sort_index()
```

`pandas-datareader` 可用但维护不活跃，不作为唯一依赖。）

### 校验时的三条口径差（否则会误判自建因子有 bug）

1. **市场**：VWRETD 成分比 French 宽（含 REITs、封闭式基金）。日频相关性
   预期 **>0.99 但不等于 1**；掉到 0.97 以下才是真有问题。
2. **规模**：自建「DlyCap 十分位 D1−D10」比 SMB 极端得多（SMB 只按 NYSE
   中位数二分且被三重中性化）。预期相关性 **0.85–0.95**、自建波动率显著更高。
   **接近 1 反而可疑。**
3. **动量**：French Mom 是 (2-12)、NYSE 30/70 断点、size 双排序、值加权、
   月度再平衡。自建 12-1 相关性预期 **0.80–0.95**；建议同时看日频相关性与
   月度累计收益相关性（后者对再平衡时点差异不敏感）。
