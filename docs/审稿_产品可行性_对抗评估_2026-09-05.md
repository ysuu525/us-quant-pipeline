# 对抗性评估：这个策略作为散户交易产品是否值得做（2026-09-05）

> red team。只读；未碰 `outputs/fold05*`–`fold35*`、`eval_sealed_*`、任何 ≥2024-01-01 的分数/标签/收益。
> 每条标【文献 / 本项目实测 / 推断】。**行内 `:N` 一律指 `experiments/ledger.md` 的行号（510 行版本）；
> `exp6.md` = `outputs/exp6_deflated_sharpe.md`。**

## 结论

**作为散户交易产品不值得做；作为研究项目值得做完。** 用登记簿自己的 haircut 缩到诚实水平后，预期净超额约
2.6–4.5%/年（相对 top500 等权池），却面对三道项目从未建模的散户专属扣减：短线全额实现的税、MOO 不支持碎股致
20 万美元以下装不下这个组合、等权池对 SPY 近十年 −3.29pp/年的跟踪缺口——**每项都与全部 alpha 同量级**。
且真实夏普 0.3–0.6 下需 17–44 年实盘才能与零区分：**产品的反馈回路比投资生涯长。**

## 1. 三档 AUM 的期望净美元/年【实测 + 推断】

口径：FT 臂、NT=5 冻结构造、纯多、相对同池等权的**超额**（非绝对收益），杠杆 1×。

开发折毛超额 12.68%/年（`:429`）。桥公式 `收益 ≈ η·IC·σ_cs`、η=0.902（`:193`）使收益对 IC 近似线性，
把 exp 6 的 IC haircut 39.9–44.0%（`:499`）转到收益端 → **期望毛超额 7.10–7.62%/年，中心 7.35%**
（旁证：项目按 0.75×0.751 独立算出 7.14%，`:430`）。每 1bp 单边成本拖 0.5543%/年。成本三段：佣金全包 0.897bp
（AUM 无关，`:510`）；冲击按 exp12 平方根 p90/Y=1，$1M=1.475bp、按 √AUM 缩放（`:481`）；执行偏差**从未实测**，取 2/4/7bp。

| AUM | 单边 C（乐观/中性/悲观 bp） | 净超额 %/年 | 期望美元/年（中性） |
|---|---|---|---|
| $50k | 3.2 / 5.2 / 8.2 | 5.58 / 4.47 / 2.81 | **$2,235** |
| $200k | 3.6 / 5.6 / 8.6 | 5.36 / 4.25 / 2.58 | **$8,500** |
| $1M | 4.4 / 6.4 / 9.4 | 4.91 / 3.80 / 2.14 | **$38,000** |

**不确定性远大于点估计**：主动波动 9.59%、3.33 年 → 年度超额 SE=5.26pp，95% 区间约 ±10.3pp，
$50k 档即 **[−$2,900, +$7,400]**；且这只是开发折内部抽样误差，不含年代外推风险。

**三项从未建模的扣减**【推断，税率未核】：① **税**——年单边换手 55.4×（`:429`），收益全部短期实现；
若总收益 11%、边际税率 30%，年度税差约 3.3pp，**大于中性情景的全部超额**；5 日持有+复投使 wash sale 普遍触发，
亏损递延而收益照税（登记簿 08-27 提过一次，从未量化）。② **基准缺口**——产品交付的是「top500 等权 + α」，
可交易类比 RSP 近十年年化落后 SPY **3.29pp**【市场数据】，重演即抵消全部 α。③ **碎股不可用**（见 §4）。

**对照**：3M 美债 3.84%（2026-09-04）、SPY 近十年 15.19%【市场数据】；用户记录的澳洲存款约 5%（`:415`，未核）。
**杠杆**：Alpaca 保证金 6.25%/4.75%（`:97`）对上股权风险溢价约 5%，加杠杆放大的是 beta 不是 alpha；
开发折 −12.5% 只是**主动**回撤，总组合在 2008/2020 级事件下 −35%~−50%，L=2 即触发强平。
**同意 `:485` 的 L≤1：杠杆买不到 alpha，只买到毁灭路径。**

## 2. 真实夏普 < 0.3 的概率【实测 + 推断】

开发折 NT=5/8bp：T=839、年化夏普 0.85989、t=1.569、偏度 +0.353、峰度 5.140（`exp6.md` §1）；
按 Lo(2002) 含高阶矩 SE(SR_年化)=**0.544**。

- **频率派不缩水**：P(SR<0.3)=Φ((0.3−0.860)/0.544)=**15%**（等于假装 148 次试验不存在）。
- **贝叶斯**（先验 SR~N(0, 0.35²)；依据：HXZ 2020 下 64% 异象不显著【文献】、exp 6 自陈 N=1 时 DSR 也只有 0.943）：
  后验均值 **0.252**、SD 0.294 → **P(SR<0.3)=57%**；先验 SD 取 0.25/0.50 → **75% / 40%**。
- **DSR 口径**：N=94/148 → 0.066/0.044（`:499`），字面 P(SR>0)≈4%；但其 `Var(SR_n)` 由 6 个跨年代跨臂的
  异质夏普（−0.88..+1.00）估出，非重复抽样，**明显过严**，只作悲观上界。

**取 55–60%。** 同一后验下 **P(真实夏普 ≥ 1) ≈ 1%（先验 0.35）~ 5%（先验 0.50）**。

## 3. 实盘要多少年【推断，算术是硬的】

推断单位 = 逐日净收益、HAC 后 t ≈ SR×√年（项目实测吻合：0.86×√3.33=1.57 = NW t，`:173`）。关键是用 **haircut 后**的夏普：
毛 7.35% − 8bp×0.5543 = 净 2.92%、波动 9.59% → **SR≈0.30**；C=5bp → 0.48；C=3bp → 0.59。

| 真实 SR | t>2 所需年数 | 与 0.5 区分（双侧 80%，Δ√yr>2.80） |
|---|---|---|
| 0.86（开发折原值） | 5.4 | Δ=0.36 → **60 年** |
| 0.59 / 0.48 | 11.5 / 17.4 | 不可能 |
| **0.30（C=8bp）** | **44** | Δ=0.20 → 196 年 |

**最决定性的一条**：在最可能的参数下需 17–44 年才能证明它不是零，而「是 0.86 还是 0.30」这个决定投不投的问题需 60 年以上。

## 4. 容量上限；散户受的是相反的约束【实测】

按 exp12（p90/Y=1）冲击单独触及部署线 11.2bp 的 AUM = **$57.6M**（`:481`）。但部署线管**总** C：扣佣金 0.9bp
与执行偏差 3bp，冲击预算剩 7.3bp → 容量约 **$25M**；按 §8 把部署线收到 7.3bp 则降到约 **$5M**【推断】。
**容量对散户完全不是约束。**

**约束在下限，且此前无人记录**：每笔名义额 = AUM/250（`:480`）；执行是 MOO 须 TIF=OPG，而
**Alpaca 碎股只支持 TIF=DAY，OPG 一律拒绝**【官方文档，本次核实】→ 每笔必须整股。
K13 成交价 p50=$89.9 / p75=$190.0 / p90=$352.0（`k13_order_audit_nt5.json`）：
**$50k→$200/笔，>25% 的目标成交连 1 股都买不起，$100–200 档买 1 股即 50–100% 权重误差，组合装不下**；
$200k→$800/笔，p90 名字只能买 2 股（13% 误差）；$1M→$4,000/笔，中位 44 股，误差 2–9%，可行。

即**最小可行规模约 $500k–$1M**，恰好也是越过非零售审查线的规模。改日内市价单可拿碎股，
但已实测执行时点后移的代价（收盘竞价 vs 开盘 −3.3pp/年，`:99`）与半衰期 2 日（`:138`）——**换执行方式就把 alpha 换掉了。**

## 5. 数据集与市场：是不是 alpha 先验最低的地方

**文献方向支持这一担心**：HXZ 2020 用 NYSE 分位+市值加权后 286/447（64%）异象不显著、102 个流动性变量里 93% 不显著；
ACG 2006 的短期反转利润集中在高换手低流动性股且**小于其交易成本**；McLean–Pontiff 2016 样本外衰减 26%、发表后 58%【均为文献】。
反方是 JKP 2023：多数因子可复制、13 主题、93 国样本外成立，且**反对**市值加权【文献】。
故共识不是「大盘无 alpha」，而是「用大盘+市值加权口径去测，已发表异象大多死掉」。

**但本项目近代实测方向相反，必须直说**：E3 的 RankIC 随流动性**单调上升**（全池 +0.0207 → top500 +0.0258 → top250 +0.0287，`:132`）；
K7b 的 ADV 最流动档 q4 是全项目最强单项（+0.0305，t=3.90，7/7 折，`:202`）；而 2003–04 梯度完全反向。
**这正是确认集要回答的那一问；断言「选错了地方」既无据，也提前放弃了唯一有功效的实验。**

**换地方的代价**：小盘——EDGE 全池 2023 中位有效价差 31.5bp（`edge_cost_model.json`），55×/年换手下每多 10bp 吃 5.5%/年，
E3 实测全池按 25bp 为 **−5.60%/年**（`:131`），**算术上不可行**；换国家/频率/资产分别卡在国际数据、tick 基础设施、
无幸存者偏差的历史。**唯一低成本的换地方是换信号不换宇宙——正是信号#2/#3 在做的事。**

## 6.「低期望利润要靠高频/做市配合」

用 `IR ≈ TC·IC·√BR`（Grinold 1989；Clarke–de Silva–Thorley 2002 加入 TC）【文献】拆开：

- **宽度早已很大**：500 只 × 每年约 50 个独立换仓周期，BR 在 10³–10⁴ 量级；开发折反解毛 IR=12.68/9.59=1.32、
  IC=0.0207 → TC·√BR ≈ 64。**瓶颈不是宽度，是 IC 太小与成本底太高。**
- **提频被实测否决**：turn(T)/T 由 T=5 的 0.110 升到 T=1 的 0.336（成本 ×3.1），而 e(h) 在 h=3 见顶、
  T=1 平均边际 4.80bp/日 < T=5 的 6.85bp/日（`:194`）——**同时抬成本、降毛收益**；E5、E0 独立同向（`:129`、`:138`）。
- **做市不是同一个问题**：收入来源是价差与返佣而非预测，需要会员/托管/库存风控；且本信号被 K6b 定位在**短期动量**侧
  （mom_skip β=+0.07 t=3.6、rev1 β=−0.12 t=−2.2，`:192`），即流动性**需求方**，**与做市符号相反**。

**几乎没有量化论文敢公开自己的搜索路径与被否方案。** 这条链条（登记簿 → 实测 N=148 → Harvey–Liu haircut →

**(c) 基础设施与流程可复用且已跑通。** `--sealed` 与读取守卫、预注册清单（sha256+OTS+`--verify` 76/76）、盲功效关、

## 用户三句话的逐条评估

**①「夏普和 IC 都非常感人，起码夏普要到 1 才能用」——前半错，后半半对。** IC 0.0207 是横截面信号的常见量级，
haircut 后诚实期望只有 0.0116–0.0124（`:499`）；夏普 0.86 的 t 仅 1.57，与零不可区分，且是 148 次登记试验后挑出来的。
「夏普要到 1」**表述错**：0.86 是相对等权池的**主动**夏普、不是组合总夏普，两者不可比；固定夏普门槛也不是正确决策规则
（预注册的 `C ≤ BE−预留` 才是）。但**方向对**：真实夏普 0.3–0.6 下需 17–44 年才能与零区分（§3）；
按他自己的标准算账，**P(真实夏普 ≥ 1) ≈ 1–5%**，门槛有 95–99% 概率过不了。

**②「低期望利润要靠高频交易配合（比如做市）」——半对半错。** 对的是「低单笔边际靠宽度补」，即 Grinold 定律；
错在：本策略宽度已在 10³–10⁴ 量级、瓶颈是 IC 与成本底，提频被三处实测否决，做市是另一条收入线且与本信号符号相反（§6）。

**③「一开始的数据集和 H 选错了就怎么优化都徒劳」——原则完全正确，作为对现状的诊断则未被证实、且与近代实测相反。**
支持原则的教科书实例就在本项目：2003–04 信号长在最不流动的两档，该期 top500 半价差 20.3bp 对上盈亏平衡 1.7bp，
**差 11.9 倍**（`:208`），那个年代任何优化都救不回来。但近代七折 IC 随流动性单调上升、最流动档是全项目最强读数
（`:132`、`:202`），文献先验说这里不该有 alpha 而本项目量到了——**要么是真发现，要么是 top500 在近代折上被选出来的假象；
分辨二者的实验已经建好、算完、只差读。现在下「选错了」的结论，是在唯一有功效的证据到手前放弃它。**
