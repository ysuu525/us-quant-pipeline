## 一、结论先行

**H_B 的三个分句，两个被证伪，第三个被替换成更坏的形式。**

**① 「等权增益明显不如优化权重」——被证伪。**（文献证据 + 可核对推导）两信号、ρ=0.2、IC 比 0.65–0.97 时，等权相对最优权重的理论 IC 损失仅 **0.03%–3.3%**（下式(5)）。而本项目实测的"看数据选参"偏差是 **+0.0070**（CLAUDE.md §二实例甲）。**估权代价比等权损失大一个数量级。** DeMiguel-Garlappi-Uppal(2009) 的机制正是这个：均值估计误差主导，N=25 需约 3000 个月估计窗才让优化解稳定超过 1/N。Dawes(1979) 的 improper linear models、Wainer(1976) 的"平顶"结论同向：目标函数在最优权重附近是二阶平坦的。

**② 「先读单臂、再读预注册合成会使确认失效」——被证伪。** 固定序贯（fixed-sequence / hierarchical）检验：顺序**事先写死**、H1 拒绝后才读 H2、**两个终点都用满 α=0.05**，强控 FWER，无需任何 α 拆分。这是 FDA《Multiple Endpoints in Clinical Trials》(2022) 的标准手段。「先单臂后合成」恰好是正确的顺序，因为单臂功效更高、更该放在门控第一位。

**③ H_B 没问到的两件事才是致命的（推断，基于下节数值）：**
- **(a) 等权秩相加在给定参数下可能是负增益。** 对信号#2 施加与信号#1 同样的 25% 赢家诅咒折价后，期望 ΔIC ∈ **[−0.0007, +0.0018]**，**跨零**。
- **(b) ΔIC 的配对 MDE80 = 0.0050–0.0079，是 SESOI(0.002–0.0031) 的 1.6–4.0 倍 → B 层。** 与读取顺序无关：**这个比较在 31 折上结构性不可回答**，正如 CLAUDE.md §二已经为正交臂算过的（0.0088–0.0121 的配对 SE）。

## 二、第 5 条：功效计算（公式与中间数）

记截面标准化后信号 s₁,s₂，截面秩相关 ρ₁₂=0.2；IC_j = corr(s_j, r)。

**(1) 等权合成 IC**（Var(s₁+s₂)=2(1+ρ₁₂)）：
```
IC_c = (IC₁+IC₂)/√(2(1+ρ₁₂));  √2.4 = 1.54919, k ≡ 1/1.54919 = 0.64550
```

**(2) 稀释门槛**（IC_c > IC₁ 的充要条件）：
```
IC₂ > IC₁·(√(2(1+ρ₁₂)) − 1) = 0.54919 × 0.0155 = 0.008513
```
→ 信号#2 的 IC 必须超过 0.0085，等权合成才不是稀释。**这是整个方案的枢纽数。**

**(3) 名义参数下**（IC₁=0.0155）：

| IC₂ | IC_c | ΔIC | 相对增益 |
|---|---|---|---|
| 0.010 | 0.016460 | **+0.00096** | +6.2% |
| 0.0125 | 0.018074 | +0.00257 | +16.6% |
| 0.015 | 0.019687 | +0.00419 | +27.0% |

**(4) 施加同等 25% 赢家诅咒折价**（信号#2 的超参也在折 36–42 选，凭什么不折？）：IC₂ ∈ [0.0075, 0.01125]
```
IC₂=0.00750 → IC_c = 0.02300/1.54919 = 0.014847 → ΔIC = −0.00065  （合成变差）
IC₂=0.01125 → IC_c = 0.02675/1.54919 = 0.017267 → ΔIC = +0.00177
```

**(5) 最优权重与等权损失**：w ∝ Σ⁻¹IC = (IC₁−ρIC₂, IC₂−ρIC₁)，IC_opt = √(IC′Σ⁻¹IC)
```
IC₂=0.010: w ∝ (0.0135, 0.0069) → (0.662,0.338)
           IC_opt = √{[0.00024025 − 0.000062 + 0.0001]/0.96} = √0.000289844 = 0.017025
           等权/最优 = 0.016460/0.017025 = 0.9668  → 损失 3.3%
IC₂=0.015: IC_opt = √{[0.00024025 − 0.000093 + 0.000225]/0.96} = 0.019692
           等权 0.019687 → 损失 0.03%
```

**(6) 配对 ΔIC 的标准误**。关键：Δ_t 是 IC₁,t 的线性组合，
```
Δ_t = IC_c,t − IC₁,t = (k−1)·IC₁,t + k·IC₂,t,   k−1 = −0.35450
设 σ₁=σ₂=σ，c₁₂ ≡ corr(IC₁,t , IC₂,t)（逐日 IC 时间序列相关，≠ ρ₁₂）：
Var(Δ)/σ² = (k−1)² + k² + 2k(k−1)c₁₂ = 0.12567 + 0.41667 − 0.45760·c₁₂
SE(Δ) = SE(IC₁) × √(0.54234 − 0.45760·c₁₂)
```
c₁₂=0.10 → ×0.7047 → **0.00211**；c₁₂=0.25 → ×0.6543 → **0.00196**；c₁₂=0.40 → ×0.5994 → **0.00180**。
若慢信号的 HAC 长期 SE 是快信号的 1.5×（21 日 vs 6 日持续性，NW lag 必须加长）：
`Var(Δ)/σ₁² = 0.12567 + 0.41667×2.25 − 0.68641c₁₂`，c₁₂=0.25 → √0.89157 = 0.9442 → **SE(Δ)=0.00283**。
**诚实区间：SE(ΔIC) ∈ [0.0018, 0.0028]。**

**(7) MDE80**（双侧 5%，Z = 1.96+0.8416 = 2.8016）：
```
MDE80 = 2.8016 × SE(Δ) ∈ [0.0050, 0.0079]
```
**SESOI**：经济锚——开发折 IC 0.0207 ↔ 毛超额 10.5%/年 ⇒ 约 0.5%/年 per 0.001 IC；要求合成至少值 +1%/年 ⇒ **SESOI ≈ 0.002**；相对锚（20% 相对改进）⇒ 0.0031。
**MDE80/SESOI = 1.6–4.0 ⇒ B 层。ΔIC 不得作为确认性检验。**

**(8) 若硬做的功效**（取 SE=0.0020）：ΔIC=+0.00096→z=0.48→**7%**；+0.00257→z=1.29→**25%**；+0.00419→z=2.09→**55%**。**最乐观情形也够不到 80%。**

**(9) 但"合成 vs 零"是 A 层**：`Var(IC_c)/σ₁² = 2k²(1+c₁₂) = 0.41667×2×1.25 = 1.0417` → SE(IC_c) = 0.003×1.0206 = **0.00306**。
`t_合成 = 0.0165/0.00306 = 5.4`；`t_单臂 = 0.0155/0.003 = 5.2`。**两条 vs 零的读数都远超门槛 → 都可做确认性检验。**

**(10) 期限口径致命警告（推断）**：若 IC₂ 的 0.010–0.015 是在 **21 日标签**上测的，换到本项目的 6 日标签约乘 √(6/21)=0.535（IC_h ∝ √h，signal 均匀载荷时），得 **0.0053–0.0080，全部低于稀释门槛 0.008513**。此时逐日秩相加**确定是负增益**。**在做任何事之前，必须先把信号#2 的 IC 在 6 日标签上重测一遍。**

## 三、第 1–2、4、6 条（压缩）

**第 1 条（文献证据）**：DGU(2009 RFS) 对 7 组数据集、14 种优化模型，**没有一个在夏普上稳定击败 1/N**；机制是均值估计误差。Kelly-Malamud-Zhou(2024 JF) 主张 P≫T 的无岭回归复杂度有益；Nagel(2024/25) 的反驳是该结论对收缩强度极度敏感，低维+适当收缩可复现大部分收益——**双方共同的可操作结论是"收缩强度是主变量，不是特征数"**，而等权就是无限收缩。Avramov-Cheng-Metzker(2023 MS) 显示 ML 增益集中在微盘/困境/低流动性，加上真实约束后大幅衰减——**与本项目 top500 口径直接冲突，是选信号#2 时的先验**。Grinold《Signal Weighting》(JPM 2010) 给出的最优权重就是 Σ⁻¹IC，即上式(5)。

**第 2 条**：(a) 逐日秩相加 = 上面算的那个，在本参数下增益跨零，且换手由快信号主导（慢信号被摊薄成噪声）。(b) 慢信号作筛子：等价于条件双重排序，保留快信号的换手结构，把慢信号变成一个**零参数的定性约束**——但"前 50%"这个阈值是自由参数，必须先验固定（建议 50%，因为它是唯一无参考点的默认）。(c) **慢信号定持仓集合与仓位、快信号定进出时点**——这是 Lopez de Prado 的 meta-labeling 架构；它**降低**而非提高换手，且天然对齐两个期限。(d) 分组合等权：Ghayur-Heaney-Platt(2018 FAJ) 与 AQR Fitzgibbons 等(2017 FAJ,"Don't Just Mix, Integrate")结论相反方向的著名对峙，AQR 主张整合（signal blending）在纯多下因子暴露更高。**推断**：本项目应选 **(c)**，其次 **(b)**，**不选 (a)**。理由：Garleanu-Pedersen(2013 JF) 的"aim portfolio"结果说明有成本时应**降低**快衰减信号的权重；而 (a) 恰恰给快信号 50% 权重并让它决定全部换手。CLAUDE.md §五已经写明 RankIC 与钱只有 corr≈0.87——**IC 口径系统性低估慢信号（同样的累计 alpha、远低的换手）**，用 IC 选合成方式会系统性选错。

**第 4 条（严格论证）**：设 D=折36–42，C=折05–35，h = g(f₁,f₂) 其中 g 零参数。因为 h 是 D-可测的固定函数，且 C 未参与 h 的选择，**E[IC_C(h) | 选择事件] = h 在 2005–2020 的真实 IC。IC_C(h) 与 IC_C(h)−IC_C(f₁) 都是无偏的。** 赢家诅咒**不进入 C 的估计量，只进入先验**——所以它污染的是功效计算和决策权重，不是读数本身。

**隐藏污染渠道（按危害排序）**：
1. **信号#2 的来源自带 2005–2020 的样本内性**。若信号#2 是"经典异象叠加"，那些异象是全行业在 1963–2020 美股上挖出来的；McLean-Pontiff(2016 JF)：97 个变量样本外低 26%、发表后低 **58%**。**此时折 05–35 对信号#2 根本不是样本外**，合成读数的认识论地位低于单臂读数——这会**拉低整个 C 读数的等级**。这是最严重的一条，且是"经典异象"分支独有的。
2. **看过 f₁ 在 D 上的分数分布/残差后设计 f₂ 的特征**。此时 (f₁,f₂) 是在 D 上联合优化的，ΔIC 本身成为被选量，25% 折价严重不足。**必须硬性禁止：f₂ 的特征集在看任何 f₁ 残差之前冻结并登记。**
3. **共享管线继承 D 的选择**：top500/FRS/6 日标签/进前 10% 出前 30%/六袖套，全部是为**快**信号调出来的，对慢信号#2 是系统性劣势。这不是统计偏差，是结构性的——必须披露。
4. **"零自由参数"通常是假的**：秩 vs z-score、winsorize、缺失值前向填充天数、universe 取交集还是并集后重排——每一个都是参数。**必须逐条枚举并冻结。**

**第 6 条**：Harvey-Liu-Zhu(2016 RFS) 的 t>3.0 是给**新因子发现主张**的，不是给组件的。Harvey-Liu(2020 RFS,"False (and Missed) Discoveries")明确论证过高门槛制造 Type II 错误，主张门槛应随先验与漏检成本变化。Harvey-Liu《Lucky Factors》按**边际贡献**而非独立 t 判定新因子。**推断**：组件不需要各自 t>2.8；但本项目的约束不是哲学，是 **31 折是一次性资源**——所以组件只能在开发折上按 B 层先验规则准入（其读数明确标为"非无偏"），**确认集只花在组合上**。

## 四、推荐方案

**合成规则（零参数、先验固定，不是性能发现）**：
> 慢信号#2 的截面秩前 50% 构成**可持有集**；在可持有集内按信号#1 执行现有冻结规则（进前 10%、跌出前 30%、六袖套、top500 ADV、t 收盘出分 / t+1 开盘成交）。信号#2 缺失或陈旧超过 21 个交易日的名字视为**不在可持有集**。

选它的理由按 CLAUDE.md B 层优先序：自由参数最少（唯一常数 50% 是无参考点默认）、不增加换手（只会减少）、对"IC 低估慢信号"这一口径缺陷免疫（因为判据是钱不是 IC）、且与 Garleanu-Pedersen 的成本调整方向一致。**逐日秩相加（方案 a）被排除，理由是上式(2)(4)(10) 显示它在本参数区间可能是负增益。**

**验证顺序**：

| 阶段 | 在哪做 | 做什么 | 不做什么 |
|---|---|---|---|
| 1 | 折 36–42 + 内层 CV | 信号#2 全部超参；6 日标签上重测 IC₂；合成规则全部实现细节；换手与成本 | 不读 ΔIC 做任何判定 |
| 2 | 不消耗折 | 小额真钱成本实测（v4 修订 2 已定），**先于**冻结 | — |
| 3 | 折 05–35，一次 | 固定序贯：**H1 单臂 vs 零 → H2 合成 vs 零**，各 α=0.05 | **不把 ΔIC 当检验**；不看年份/ADV 档/替代阈值 |
| 4 | 折 44–45 | 管道洁净复核 | 不担任终审（t 天花板 0.88） |

**若 IC₂ 在 6 日标签上重测后 < 0.0085**（式(2)），**整个合成方案在阶段 1 终止，不进入折 05–35**。这是唯一能保护 31 折的止损点。

**预注册必须写死的 7 条**：
1. 信号#2 的特征集与超参网格，**及"在看任何 f₁ 残差前冻结"的时间戳**；
2. 合成规则全文，含 50% 阈值、缺失/陈旧处理、标准化方式、universe 交集规则；
3. 固定序贯的**顺序**（H1 单臂 → H2 合成）与各自 α=0.05，及"H1 不拒则 H2 不读"；
4. **部署决策规则**（关键）：`部署合成 ⟺ H1 且 H2 均拒绝 且 C 上 ΔIC ≥ 0`。这是**预注册规则不是检验**——否则"读完两条再挑好的"就是在确认集上做选择，H_B 后半句在那种做法下是对的；
5. ΔIC 明确标记为 **B 层诊断量**，只报点估计与 CI，**禁止据其做淘汰或推翻**，措辞按 CLAUDE.md §二强制格式；
6. 信号#2 若含已发表异象，须列出清单与首次发表年份，并在结论中声明"折 05–35 对信号#2 不是样本外"（McLean-Pontiff 折价）；
7. 三个 SESOI/MDE 数对（单臂 vs 零、合成 vs 零、ΔIC）连同上式(6)(7) 的中间数一并登记。
