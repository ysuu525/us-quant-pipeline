## 2. 规则定义（先验固定，零自由参数）

**Rule E（进场过滤）**：信号日 t，若名字 i 的**预期下次公告日** `rdq_hat_i` 满足

```
rdq_hat_i − 1 日历日  ≤  某交易日 d  ≤  rdq_hat_i + 1 日历日，且 d ∈ [t+1, t+6]（交易日）
```

则 i 在 t 日**不得新建仓**（从当日入选名单剔除，名额由下一名递补，其余管道不变）。

固定项：
1. **`rdq_hat`** = 同财季**上一财年**的实际公告日 + 1 年，取最近的未来一次（与 exp13 任务书 §4.2 同源，零前视）。
2. **±1 日历日 slack** 与 exp13 D3 的 `ea_day` 定义相同（覆盖盘后公告 / 隔日反应），**不是调出来的**。
3. **窗口 [t+1, t+6]** = 冻结的 6 日持有期，不另设。
4. **已持仓不强制退出**（退出规则维持冻结的「跌出前 30% 才卖」）。动作只有「不买」。
5. **无 `rdq_hat` 的名字视为可进**（不惩罚缺数据）；披露其占比。
6. 实盘若拿到**公司确认的**前瞻日期，以确认日期替代 `rdq_hat`（更准，且仍是 t 日公开信息）；回测只能用 `rdq_hat`。两者差异 → §4。

## 3. 边界（与冻结协议的关系）

- **不进 v4**：确认集读取按 v4 冻结构造，本规则**不出现**在 H1 / H1b / H2 / E 任何终点里。
- **不进 v4 §3 释放清单**、**不在解封读取时计算**。
